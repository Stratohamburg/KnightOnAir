# Proposal

## Why

现有四个时代入口采用无尽巡航。前 20 关需要可逐步学习的任务、持续可读的局内目标和明确的胜负。现有风场、云层和光照需要由关卡统一配置，才能复现教学条件，并在后续关卡安排天气和时段变化。

## What Changes

- 新增四章 20 关战役。每关定义设计目标、任务条件、遭遇顺序、局内引导、出击装配与环境。机枪、投弹和锁定教学按固定靶、移动靶的顺序展开。
- 新增局内任务判定，覆盖指定击毁、限时拦截、保护、护送和多阶段任务。出击、战斗与结算使用同一关卡身份和目标状态。
- **BREAKING** 出击页默认入口切换为第 01 关战役。现有四种时代体验通过独立的自由巡航入口访问，战役与巡航使用各自的选择和结算语义。
- 增加战役首次通关、下一关解锁、重试和已通关关卡重玩。兼容现有机体解锁和档案数据。
- 增加可配置的天气预设与过渡，以及黎明、白天、黄昏、夜间和局内时段过渡。模拟时间驱动环境，HUD 在低能见度与夜间保持任务可读。

## Capabilities

### New Capabilities

- `world/campaign-missions` — 战役关卡配置，以及 01–20 关逐关设计目标和验收场景。
- `battle/mission-objectives` — 任务进度、目标实例、保护与护送、阶段推进和胜负判定。
- `world/weather` — 战斗风、云、雾和降雨状态及可复现的局内过渡。
- `world/day-night-cycle` — 局内时段、昼夜推进和场景光照一致性。

### Modified Capabilities

- `battle/session-lifecycle` — 分离战役与自由巡航的入口、出击装配及终局流程。
- `battle/encounter-director` — 为战役编排必需目标、预留预算并复用安全生成规则。
- `battle/battle-hud-and-event-feedback` — 展示当前任务、目标方向、操作教学及环境变化。
- `battle/in-run-progression` — 将胜利和任务失败纳入局内统计的结算条件。
- `app/persistence-and-meta-progression` — 按关卡 ID 保存通关和顺序解锁，沿用历史档案。
- `world/combat-content-and-eras` — 按时代解析内容，通过独立关卡配置选择任务和环境。

## Impact

涉及战斗固定步进、敌群导演、队伍及武器目标选择、路线和阶段状态、出击与结算页面、存档、战斗 HUD、风场、云层、地表、水面和场景光照。复用已有机体、路线和内容库，炮靶、友方任务对象与环境配置通过内容 ID 接入。
