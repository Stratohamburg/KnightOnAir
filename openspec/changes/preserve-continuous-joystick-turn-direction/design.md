# Design

## Context

当前 `VirtualStick` 将指针位置平滑为单位方向和行程，`World` 把方向转换为绝对目标航向，`FlightDynamics` 再通过归一化角度误差驱动 bank、turnVelocity 和 heading。这个链路保持了摇杆指向和目标航向的一致性，但角度归一化会丢失连续拨动轨迹在 `-π/π` 临界点上的方向信息。详见 [proposal.md](./proposal.md) 的动机与范围。

输入层已经有统一的指针捕获、死区、平滑、加力和模式重置路径。模拟层使用固定步长，玩家、AI 和回放共享 `ControllerIntent`。设计需要把连续拨动信息接入现有快照，而不是建立一条只服务触控的旁路。

## Goals / Non-Goals

**Goals:**

- 保持绝对目标航向和摇杆距离决定油门的核心操作。
- 为连续顺时针或逆时针轨迹提供可复现的方向偏好。
- 只在目标航向接近角度分支临界区时使用有向误差，减少对现有转弯手感的影响。
- 通过锁定阈值和反向滞后消除临界点附近的方向抖动。
- 让输入中断、模式切换、固定步长和回放都拥有明确的状态生命周期。

**Non-Goals:**

- 改变 AI 的目标航向生成或默认最短路径转向。
- 改变机体、损伤、bank 限制、速度和加力的平衡参数。
- 增加独立的纯相对转向模式。
- 为连续拨动方向增加新的 HUD、音效或 Three.js 内容。

## Decisions

### Preserve absolute heading semantics

输入快照继续包含归一化方向、移动强度、普通油门和加力请求。新增的连续转向偏好只表达手势轨迹的方向，不能替代目标航向。键盘输入保持绝对方向语义，并可省略连续拨动偏好。

这样可以保留当前触控与键盘的等价行为，也能让直接把摇杆移到身后的操作继续使用普通目标航向收敛。

### Track an unwrapped gesture angle in the input layer

有效指针移动期间，输入层保存上一采样角度和累计的连续角位移。相邻采样先使用最短角差，再把角差累加到未折返的手势角度。跨越 `-π/π` 时，局部角差保持连续，因此可以判定顺时针或逆时针方向。

当累计角位移达到方向锁定阈值时产生方向偏好。反向累计位移达到更小的滞后阈值后才切换偏好。指针突然跳跃、进入死区或被重置时清除累计状态。

### Carry direction preference through the fixed-step snapshot

在玩家输入快照和控制意图中增加可选的连续转向方向字段，取值表达顺时针、逆时针或未锁定。字段进入固定步长世界更新，也进入网络控制器或回放缓冲的样本。

AI 没有该字段时继续使用最短角度误差。这样相同的输入快照序列可以在玩家、回放和不同渲染帧率下复现同一转向选择。

### Use a bounded directed-error override

飞行积分器先计算当前最短角度误差。只有同时满足以下条件时才使用有向误差。

1. 输入快照提供已锁定的连续转向偏好。
2. 目标航向位于最短路径分支的临界保护区。
3. 飞机尚未进入目标航向收敛窗口。

有向误差沿偏好方向取 `0` 到 `2π` 的路径长度。接近目标后恢复普通收敛，避免历史手势迫使飞机绕完整圆周。边界自动回转目标拥有更高优先级，并清除旧的连续方向偏好。

### Reset state at gesture boundaries

`pointerup`、`pointercancel`、`lostpointercapture`、页面失焦、输入禁用和普通空战与轰炸模式切换都调用同一套状态清理。清理后 `active`、行程、连续角位移和方向偏好同时归零，飞机保留当前速度并进入已有的松杆滑行逻辑。

### Keep thresholds configurable

锁定阈值、反向滞后阈值、临界保护区和目标收敛窗口作为输入手感配置，集中放入现有配置入口。首轮默认值采用设计评审中的候选范围，并通过纯逻辑测试和真实手机试玩调校。

## Risks / Trade-offs

- [风险] 有向误差可能让玩家只是直接指向身后时选择长路径。→ 只有连续角位移达到锁定阈值，并且目标处于临界保护区时才启用有向误差。
- [风险] 触控采样频率变化可能影响累计角位移。→ 手势累计只保存方向快照，固定步长消费快照，测试覆盖 30、60 和 120 FPS。
- [风险] 方向锁定滞后让快速反向操作感觉迟钝。→ 反向阈值小于初次锁定阈值，并通过手机实测校准。
- [风险] 轰炸模式继承旧方向偏好会造成准心或飞机突然偏转。→ 模式切换统一清理手势状态，并要求下一次有效拖动重新建立偏好。
- [风险] 左右控制面损伤可能让玩家误以为输入被反向。→ 规格只允许损伤降低同侧响应幅度，测试固定转向符号不被损伤改变。

## Migration Plan

1. 先实现并验证输入快照和摇杆状态的规格测试。
2. 将连续转向方向接入玩家控制意图和固定步长飞行积分器。
3. 增加临界点、反向滞后、复位、模式切换和回放测试。
4. 在 360×640 与 390×844 竖屏视口进行连续顺时针、逆时针和反向拨动试玩，调节配置阈值。
5. 若实测结果需要调整阈值，只修改配置和对应验收数据，不改变绝对目标航向契约。

回滚时移除连续转向方向字段的消费，并让输入层继续输出现有方向、行程和加力字段。旧输入样本不包含该字段时，模拟自动使用原有最短角度收敛。
