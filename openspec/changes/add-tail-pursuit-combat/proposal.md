# Proposal

## Why

当前空中敌人每个固定步都在做一次“朝玩家预测位置转向”的简单追踪。它没有像真人飞行员那样读取相对位置、速度、攻击角和能量优势，再选择接近、占位、射击、脱离或重新切入。玩家因此面对的是另一架自动朝向自己的飞机，很少面对一个会做战术决策的对手。

## What Changes

- 建立由感知、战术选择和控制意图组成的 NPC 飞行员决策闭环。
- 为普通追猎机增加后方或侧后方接敌、尾后占位、速度匹配和有效射击窗口。
- 让玩家持续转弯或加力逐步破坏尾后几何，敌人根据相对角度和闭合速度选择继续追击、横向脱离或超越。
- 为追猎机、截击机、俯冲机、护航机和路线攻击机提供独立的战术目标与机动参数。
- 让敌人根据攻击角、距离、闭合速度、武器解算、受损状态和能量储备决定是否开火、保持、脱离或逃逸。
- 将导演职责限制在刷新时间、单位类型、编组和入口位置，NPC 飞行员在生成后独立驱动每个固定步的行为。
- 增加固定种子下的尾追、摆脱、超越、重新切入和战术角色测试。
- 同步空战 OpenSpec、玩法设计文档和变更验收记录。

## Capabilities

### New Capabilities

<!-- No new capability. The behavior belongs to existing battle contracts. -->

### Modified Capabilities

- `battle/air-combat-behavior`: NPC 必须通过感知和角色战术生成持续的飞行员行为，追猎机必须支持后方接近、尾后保持、玩家摆脱和失位后的重新切入。
- `battle/encounter-director`: 导演只负责刷新时机、单位角色、编组和安全入口，不能替代 NPC 飞行员的逐步战术决策。

## Impact

- 模拟控制器和敌人更新逻辑会增加相对几何快照、战术状态、动作计时器和尾后目标数据。
- 敌人配置会增加角色级战术参数，现有共享飞行积分器和分离逻辑继续复用。
- 空战回归测试会覆盖普通追猎机、高速截击机、俯冲机和路线攻击机的不同决策节奏。
- OpenSpec delta、玩法设计和验证文档会记录新的可观察行为与验收阈值。
