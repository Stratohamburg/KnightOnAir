# 飞机低模特效设计

## Context

战斗模拟按固定步推进，多步事件可能在同一画面帧交付。飞机工厂已为部分机型登记挂点与蒙皮。现有烟团、碎片和曳光共用实例批次，云层已有飞机穿越扰动。

## Goals / Non-Goals

战斗与预览共享装配来源，每个效果拥有可验证的世界或部件局部姿态。沿用提案登记的近似点及机型覆盖范围，专属几何的史料核对沿用机型档案流程。

## Decisions

- 在飞行动力步保存生效油门、加速度和转弯负荷。渲染读取实际状态，避免根据键盘、摇杆或两次画面的位置差猜测动力。
- 发射和接触快照携带弹种、实际抛壳位置、接触类别、命中时姿态和实际扣血部件。只在一次发射或一次伤害成立时交付事件。
- 用装配节点矩阵解析气流和推进来源。短时气流随风在世界空间消散，连接翼面和喷口的部分逐帧重建，以便随滚转和改装移动。
- 参数化空中 NPC 共享按配置 ID 缓存的蒙皮批次几何。每个实例将部件变换、可见性和损伤状态传给同一次绘制，装配节点继续提供活动挂点和独立表面。
- 洞口保存在实例和所属蒙皮的局部坐标，用最近三角形投影或按面积随机采样一次。维修减少活动洞口，脱落时将洞口相对碎片的姿态一起转移。
- 复用或扩展固定容量实例批次绘制立体火芯、切面烟团、薄弧、弹壳、洞痕及气流，避免逐挂点创建绘制调用。将装配标注导出成可核查的机型三视图资料。

## Risks / Trade-offs

- 多步结算与表现插值可能造成破洞偏移。记录命中时姿态，在渲染边界转换到当前蒙皮坐标。
- 满载时旧轨迹可能挤占新来源。为持续根部和逐发反馈保留容量，降低旧迹密度，并用实际整帧计数复核标准档预算。
- 模型重建可能使旧节点失效。通过稳定部件与表面标识重绑定，并在新局清除实例记录。
