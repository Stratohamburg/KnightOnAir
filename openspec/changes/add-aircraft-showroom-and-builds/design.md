# 飞机展厅与局内变形构筑设计

## Context

当前 17 架飞机共用 23 张升级。首张牌之前的合法候选数为萌芽和一战各 20 张，二战 21 张，初代喷气 23 张。局内从合法候选加权抽三张。普通可重复的强化弹药箱已有整机伤害倍率，过载核心已有整机射速倍率；专门的普通整机射速卡仍待增加。射速乘在各自动武器自己的基础频率上。炸弹使用独立投放流程。见 [升级目录](../../../src/data/upgrades.ts)、[武器与改装](../../../src/simulation/World.ts)、[机体目录](../../../src/data/aircrafts.ts)。

**当前 23 张卡的去向。** 表中写的是重做后的分类。“部件数”和“挂点数”分开显示，例如同座双联增加枪管，仍占一个枪位。

| 现有卡 | 重做归属及可见反馈 |
|---|---|
| 左侧辅助发动机、右侧辅助发动机、双侧动力组 | 提量。所选翼侧伸出短梁和独立短舱，增加一处或两处动力出口；保留单双方案互斥 |
| 左翼机枪、右翼机枪、巨型外挂翼 | 提量。前两张只接长所选侧，巨翼同时新增两段宽翼和两条火线 |
| 机背旋转炮塔、右翼端旋转炮塔、双尾防御组、翼下火箭巢 | 提量。分别抬高背部、延伸翼尖、分叉尾部、伸出翼下挂梁；炮口方向和可见发射点对应挂点 |
| 机尾装甲舱、模块化机架 | 提量。新尾段加装甲，中央新框架显示三个可用连接位，装入部件后可辨哪一位已占用 |
| 低阻力短翼、重型装甲、高压发动机、机头重型机炮 | 提质。截短翼尖、增加厚板、加宽动力出口、强化原枪座，对应机动、耐久、加速和射击动作。原有机头重炮新增独立挂点的行为在迁移到同座方案时须改卡文和容量计算 |
| 稳定炸弹舱、机头锁定雷达 | 按当前构型显示。首次获得功能时为提量，明确新舱段或延伸雷达鼻舱；已有投弹或锁定能力时为提质，显示稳定鳍或雷达罩变化与耗时前后值 |
| 凝固汽油弹舱、过载核心 | 提质。分别用可见舱盖、地面持续燃烧，以及外露核心、恢复和射速变化表达 |
| 强化弹药箱、能量冷却鳍、快拆装甲带 | 提质。弹箱和弹着、分级鳍片和恢复速度、逐层加宽的护带和机身耐久对应各自层级 |

当前燃烧舱也能进入早期机型候选，火箭巢则只在二战和喷气时代出现。卡面应读取时代实装弹数（二战六枚、喷气八枚）。重甲标称生命 +75，现行部件总上限实际增加 55；短翼标称 −12，两个新部件实际合计 +40。预览、卡面和局内 HUD 都应取最终构型差值。若保留短翼减耐久的取舍，应在部件生命预算中实现它。

## Goals / Non-Goals

展厅服务于两种操作：在同一角度比较前后两张构型，或转到机腹和背面观察侧舱、外翼、炮口。所有预览均为局外临时试装。进入实战仍要通过局内选牌逐步造出这架飞机。动力改装沿用现有加力储备、消耗、回充与重启门槛。

## Decisions

### 规格归属与调用方向

- [构筑（已有主规格）](../../specs/battle/aircraft-refit/spec.md) 定义卡能否安装、按序安装所得的构型、有效属性、轮廓与挂点。[本次构筑增量](specs/battle/aircraft-refit/spec.md) 承接提质、提量及六炮位整机提速，可在局内独立验收。
- [展厅（新增规格）](specs/app/aircraft-showroom/spec.md) 管理临时机型与卡序、视角、撤销和展示特效会话。它向构筑规则提交机型与卡序，读取候选、构型及差值，然后把构型交给现有机体工厂、挂点定义和特效批次。两处构型一致的验收归展厅。
- [机库导航](specs/app/out-of-battle-hangar/spec.md) 提供入口与返回。[局内成长](../../specs/battle/in-run-progression/spec.md) 管理 XP 和升级次数，[武器规格](../../specs/battle/weapons-targeting-and-bombing/spec.md) 管理瞄准、开火、锁定和投放。

### 展厅界面和试射

主界面底部导航将最右侧的第五项（当前为 `reservedB`）改为「展厅」，第四项 `reservedA` 继续作为预留按钮。展厅页面分成上下两块。上方约三分之二为独立室内机库展示区，机体位于构型中心，切换机体、撤销、重置、试射和返回出击按钮都放在展示区。下方约三分之一为操作区，只显示当前生效的有序卡序和合法强化卡列表。首屏选中装备机，点击展示区的“切换机体”后打开弹窗，弹窗开放全部机型供比较。手机下方强化卡列表独立上下滚动，展示区和当前生效卡序保持固定。拖动展示区绕机构型中心转动相机，保留已选朝向，按实际包围范围为最长翼尖和尾舱留边。

选择卡片时，以同一观察方向叠出浅色旧轮廓与待装部件；确认加入后移除旧轮廓。当前已生效的卡序固定在操作区顶部，显示顺序、次数和实际收益。数值卡显示一次可重复的对应动作。试射卡只播放当前挂点的开火事件和特效。卡列支持上下滚动、撤销末张和清空。会话只需记住机型 ID、有序卡 ID 和观察角度，撤销从基础机重放卡序即可恢复原状。

一次点击试射播放当前构型各挂点的展示开火事件。试射使用真实挂点、锚点、射界方向和武器特效，不创建敌机、战斗目标、锁定状态、战斗弹体、投弹命中或奖励事件。再次点击从当前构型重新播放；编辑或退出时清理旧特效并回收其资源。相机环绕只改变观察方向，不改变构型和挂点关系。

### 中心线驱动的构型布局

构筑系统维护一张由战斗配置定义的结构图。图中的每一条中心线代表一条可延展的结构路径，拥有局部方向、纵向站位、截面尺寸、连接节点和可用挂点。中心线不等同于一条固定的机身轴线。机身、翼梁、尾段、短舱、连接梁和翼层都可以拥有自己的中心线，中心线之间通过分支、平行、上下层或前后串列关系连接。

```text
                 [上翼前线] ---- [上翼外段]
                /
[左机身线] ---- [翼根节点] ---- [右机身线]
     |              |
 [前翼线]        [下翼后线]
     |
 [尾段线] ---- [尾侧炮舱]
```

一架单机身飞机可以只有一条主机身线和两条翼线。双机身飞机使用两条平行机身线，再用连接梁中心线共享翼面或武器平台。双翼机使用上下分层的翼线，前后串列双翼使用不同纵向站位的翼线。一个升级可以在已有中心线上延长，也可以从节点分支出新的短舱线、炮廊线或挂载线。

每个可放置物体使用中心线 ID、连接节点、纵向站位、横向偏移、垂向偏移和朝向。机翼延长卡在翼尖段的内侧接缝插入新段，接合两端截面，再把原翼尖段及其附件移到新段外端。发动机、枪座、炮塔、散热器和弹舱使用同一条线上的不同挂点层，位置由挂点间距规则解析。升级卡不保存机型专属绝对坐标。

布局解析分为四步。系统先从基础战斗配置创建中心线图，再按有序升级卡追加或修改中心线和连接节点，然后计算所有部件、武器锚点、发动机出口、轮廓和碰撞区域，最后从最终结构图推导翼展、机长、翼面积、质量和镜头包围范围。撤销和展厅重放从基础图重新应用卡序，避免旧坐标残留。

同一份解析结果同时提供给模拟和 3D 内容库。渲染层使用中心线截面和连接节点生成共享几何，模拟层使用相同的节点生成命中区域、枪口、尾焰和部件脱落锚点。父线或父节点损坏后，下游线段可以停止工作或脱落，其他中心线保持独立。现有机型迁移时逐架补齐经过审核的中心线、截面和节点资料，再逐步覆盖双机身、多翼层和串列翼构型。资料不完整的机型保持不可生成状态。

飞翼机体使用 `integratedWing` 机身构造。中心舱只保留驾驶舱、核心和必要的纵向截面，左右翼根从同一结构中心线展开，连续翼面负责主要机身体积。翼根发动机和后缘控制面直接挂在这条飞翼结构上，并使用该机型自己的截面和边界记录。

### 翼段、动力和机身的装配

**每侧、每层、每组翼各有一道翼尖接缝。** 原装半翼由翼根段和翼尖段组成。该半翼自带一台发动机时，默认在两段之间加入承载短舱的发动机段。机鼻或机尾的发动机属于机身线。若一侧配置多台翼发，则逐台配置发动机段和挂点。

| 操作顺序 | 从翼根向外读取右翼 |
|---|---|
| 原装翼载发动机 | 翼根 → 发动机段 → 翼尖 |
| 加一节机枪段 | 翼根 → 发动机段 → 机枪段 → 翼尖 |
| 再加一节辅助发动机段 | 翼根 → 发动机段 → 机枪段 → 辅助发动机段 → 翼尖 |

两张卡若各带 1 米直线翼段，沿该翼中心线的长度累计增加 2 米。上反或有后掠时，水平翼展取端点的实际横向投影。原翼尖沿新段末端的局部方向就位，保留部件身份、损伤和翼尖附件。枪座与短舱分别占用各自翼段，净距按实体轮廓和桨盘旋转范围验收。

**翼形从机头朝机尾观察，按翼根至翼尖的次序记录。** 平直翼各段等高，上反翼向外升高，下反翼向外降低。海鸥翼内段上扬，外段趋平或下折；倒海鸥翼内段下折，外段回升。机型记录折点及其两侧方向。默认沿翼尖接缝处的外翼方向插段，接缝两端的高度、前后缘和厚度连续，原有折点保留。上、下翼层以及前、后翼组分别指定截面与走向。

**发动机位置和桨盘位置分别配置。** 发动机座指定所属机身或翼段、前后站位和轴向。牵引式把桨盘装在桨轴前端，推进式装在后端。桨毂对准轴心，桨叶绕该轴转动；改装后检查完整旋转范围与相邻翼面、机身、尾翼和挂载的净距。喷气短舱则由进气口和喷口表达前后方向。展厅试射和战斗取相同挂点。

**机身线沿途带有截面。** 在机鼻、驾驶舱、翼根连接处和尾段记录宽、高及轮廓，截面之间形成连续外壳。前置机鼻发动机用发动机罩衔接桨毂；后置推进式由后机身或短舱收束到后桨轴座，并给桨盘留出空间。插入尾舱时，新舱两端匹配相邻截面，尾翼和尾端附件随下游段移动。双机身按各自的截面和安装点分别成形。验收从正面辨认翼形，从侧面辨认桨盘前后，从俯视辨认机鼻、座舱和尾段的宽度变化。

### 通用提质牌与扩建牌

数值为首轮试玩值。普通卡应当在早期单枪和后期多炮位构型都能出现。安装顺序可改变中途打法，单纯的整机倍率在最终构型上始终一致。

| 首批卡族 | 玩法、适用范围和视觉 |
|---|---|
| 快速供弹（普通，可重复） | 全机自动武器射速每张 ×1.15。枪口火光和曳光跟随各挂点开火事件。两张为 ×1.3225；屏幕显示本机有几个挂点获益 |
| 强化弹药（沿用弹药箱） | 全机自动武器伤害每张 ×1.12，显示弹着与同一靶标的耐久变化。多个枪位各自继承 |
| 同座双联 | 适用于单管直射枪位。枪座变双管，齐射两发，每发起测为原伤害的 65%。双管分别出火，共用原枪座生命；卡面指明升级的枪座 |
| 发动机增压、额外散热器、快速冷却回路 | 首轮分别测试加速 +18% 且加力消耗 +10%、持续消耗 −20%、回充 +30%。宽桨叶或喷口、外置散热百叶、松开时开启的回流口对应三种行为 |
| 稳定投放架、炮塔快转座 | 同条件下稳定速度起测 +20%、炮塔回转速度起测 +25%。比较收拢瞄准圈、跟踪同一横穿目标的时间 |
| 左／右翼延长机枪段、尾段侧射舱、外置发动机短舱 | 每次接上一节可承载的结构；第二张同侧翼卡继续向外接。左尾侧舱与正后方双尾炮各有射界，补右舱可利用既有尾段 |
| 串列弹舱、浮筒外托架、飞艇舷侧炮廊、喷气翼尖发射轨 | 依次在机身中段、浮筒横撑、吊篮舷侧、翼尖增加实体和发射点。串列弹舱沿航线连续投两枚，初测每枚原伤害 65%；其余结构按下表的机型形态装配 |

### 与现有模拟及内容库衔接

- 从 `World.openUpgrades` 提取两处都可调用的候选资格判断，局内继续按原规则抽三张，展厅枚举全部合法卡。按当前构型解析卡的最终改装分支、前后属性和容量，由同一安装逻辑应用。机型选择遍历战斗的可玩机目录，基础装备、升级、部件、挂点、武器与视效通过战斗内容 ID 解析。展厅仅持有临时选择、有序卡 ID 和观察角度，所有构筑数据和数值直接取自战斗配置及其计算结果。展厅展示会话不启动战斗步进，不创建敌机或战斗目标。本文机体与卡牌盘点仅记录设计时的内容规模。
- 沿用 `stats.fireRate` 和 `stats.damage` 在实际开火时计算倍率。以六个炮位各自的基础频率为准，普通射速卡 ×1.15 同时作用于六个挂点；满射界持续交战时，总理论发射频率也提高 15%。转塔转动、失锁、损伤和目标离开射界仍由各挂点单独处理。
- 构型布局由中心线结构图解析。基础战斗配置定义主机身线、翼线、尾段线、短舱线和连接梁线，以及每条线的节点、截面、站位和挂点层。翼部提量卡在所选翼线的翼尖段之前插段。其他结构卡在配置指定的接缝插段或从节点分支。左右、上下和前后线段分别维护自身长度，最终翼展、机长、翼面积、质量、受击覆盖和挂点锚点由解析后的结构图派生。父线或父节点脱落时，下游部件和武器停止工作，其他中心线保持独立。
- 双机身、双翼和前后串列双翼使用多条中心线表达。双机身由平行机身线和连接梁线组成，双翼由不同垂向站位的翼线组成，串列双翼由不同纵向站位的翼线组成。新增部件必须声明所属中心线和挂点层，部件距离由连接节点和间距规则计算，同一中心线上的多次扩建逐段累加。
- 展厅使用独立临时构型，不调用正式出击、奖励、存档入口或战斗目标流程。机体工厂为战斗和展厅消费同一构型；枪口和尾焰经现有锚点与特效批次呈现。切机、撤销和退场释放预览实例持有的内容租约。
- 展示模式跳过地形、植被和体积云更新，只保留室内机库背景、机体、挂点和展示特效，避免拖动相机时执行与构型观察无关的场景更新。

## Risks / Trade-offs

- **同屏六个炮位的火光可能盖过枪口差异。** 在低画质优先保留每个真实发射点的短火光，减少烟雾和次要粒子。允许武器各按自身节奏开火。
- **宽翼长尾容易挤出手机展示窗。** 以实际构型边界取景，前后对照使用能容纳两种构型的共同尺度，避免自动缩放掩盖增长幅度。
- **能在展厅拼出、局内抽不到的组合会误导玩家。** 后期验收用同一条合法卡序走正式升级流程；随机抽牌由可复现种子或测试控制，构型、挂点和倍率走同一配置入口，展厅试射保持展示会话边界。
