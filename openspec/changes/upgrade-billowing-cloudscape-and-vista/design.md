# Design

## Context

参见 `proposal.md` 及游戏文档 `docs/RENDERING_GUIDE.md`（“俯视角视觉原则（光遇·云野基线）”）。

本游戏在 360×640 移动端竖屏下采用**固定俯视角**（默认巡航 `pitch: 52°`, `fov: 48°`, `distance: 66`），视线最高边缘仍向下俯视约 `28°`：
- 屏幕内完全看不到远处天空穹顶与地平线，有效可视范围仅是玩家周围约宽 `35~70` × 纵深 `120` 的局部区域；
- 首版美术目标为**《光·遇》云野（Daylight Prairie）**的晴天多云体验——用一组一组扎实饱满的巨型白云墙分隔开不同晴朗陆地/河口区域，而不是全屏低空云海或阴天薄雾；
- 上一轮实验性改动（加入全图 `seaDensity` 低空云海、近景 `valleyMist`、广角 `fov: 62°`、空域无条件 3-tap 域扭曲以及嵌套 2–3 步完整 `sampleCloudField` 太阳循环）导致了“晴天变阴天”和 3D 纹理采样暴涨 ~15 倍（严重卡顿），必须在本次设计中彻底纠偏并固化为长期规则。

## Goals / Non-Goals

**Goals:**
- **视野内 100 分，视野外 0 分**：回归原版 `pitch: 52°`, `fov: 48°`, `distance: 66` 的强冲击云墙构图，将全部渲染算力聚焦于当前视口内可见的云墙、云顶、云影和阳光草地。
- **晴天多云、云组分隔区域**：彻底移除全图 `seaDensity` 与近景 `valleyMist`，恢复云组之间 100% 晴朗通透的阳光陆地与河道。
- **俯视角 3D 立体翻涌冲击力**：强化云顶菜花球泡起伏、饱满利落边缘与云野奶油暖白/清澈天蓝褶皱反差；支持**整体移动严格跟风场 + 原地持续缓慢三维形变及有界轻微局部偏移**。
- **高性能低采样开销**：实现 2D 宏观空域早退（晴空 0 次 3D 采样）、单步 2–3 次 3D 采样的太阳方向导数自阴影、极速宏观云影贴图刷新、以及低面数软法线球簇树冠（整场景三角面压回 `~55k~65k` 量级）。

**Non-Goals:**
- 不调整巡航俯角去强行露出天空地平线，也不为视锥外的天际云海增加任何额外采样。
- 不铺设覆盖晴朗区域的全图低空云海或近中景低谷雾。
- 不修改 `src/simulation` 的固定步进飞行、地形高度、路线与碰撞规则。
- 不引入外部贴图、模型或额外多 Pass Bloom 后处理管线。

## Decisions

### 1. 恢复晴天多云分组云墙格局，彻底移除全图 `seaDensity`

**方案**：
- 删除 `sampleDistantBillow` 中的低空铺底云海 `seaDensity`（以及 CPU `density()` 中的对应分支），云层分布完全回归 `columns` 2D 宏观布局图（东侧高墙、西侧云脊、北侧横切云桥、河口开口）与近景 `wallVolume` 巨型云墙。
- `columns` 保持 `RepeatWrapping` 以便玩家飞出局部区域后远方依然有分组云带，但在无云区域（`column.b < 0.22`）严格返回 `0`，确保区域之间 100% 晴朗无云。

### 2. 俯视角 3D 原地翻涌与轻微局部偏移（严格解耦风场整体移动）

**方案**：
- **宏观风漂移**：`drift` 依然严格由 `WindField.sample(x, z)` 积分驱动；零风速下 `drift` 增量为 `0`，整组云墙的宏观世界坐标保持固定。
- **原地翻涌 + 有界轻微局部偏移**：
  - 在 `CloudFlow` 中提供**零纹理开销的解析三维轻微局部偏移**（基于确定性低频 `sin/cos` 组合，有界且零均值，幅度约 `±1.2~1.8` 世界单位，无任何净水平漂移），叠加在命中云体后的 3D `billowNoise` 采样坐标上，同时沿 `y - selfTime * riseRate` 持续缓慢向上推进；
  - 对近景 `wallVolume` 同样使用 1 次 `wallVolume` 体素采样 + 1 次上升 `billowNoise` 菜花雕刻（取代原有 5 点盒式模糊），让大云墙既保持拔地而起的厚实云瓣骨架，又在表面持续缓慢鼓泡、舒展和轻微游动，暂停时全部冻结。
- **为什么用解析微移替代 3-tap 3D `billowWarp`**：
  - 3-tap 3D 纹理域扭曲每步要消耗 3 次昂贵的 3D 三线性采样，且在空域白白浪费；解析 `sin/cos` 三维微移几乎零 ALU 开销，且严格有界、零均值、确定性可复现，能同时实现“持续缓慢形变 + 轻微局部偏移”的自然云朵观感。

### 3. 路线 A：解析 Smooth-Min Metaball SDF + Sphere Tracing 奶油体积云（彻底消除水平分层）

**为什么放弃低步数固定步长密度体渲染**：
- 在无 TAA 时间抗锯齿的移动端单帧下，低步数（12–24 步）固定步长密度积分存在无解三角：加蓝噪/IGN 抖动会出现明显雪花噪点，不加抖动或提高密度阈值必然出现等距水平切层/等高线，而把云调薄又会变成糊状雾团。

**方案（`src/rendering/CloudLobes.ts` + `src/rendering/Cloudscape.ts`）**：
- **解析分组云簇与平滑融合 SDF**：
  - `CloudLobes.ts` 基于确定性布局与外围扇区，每帧在风场偏移后的局部视野内裁剪出最多 `4` 簇 / `32` 个平滑融合云瓣（`ORIGIN_CLUSTERS` 留出宽阔晴朗河口通道，左右两侧云墙与北侧云桥均位于 360×640 竖屏可视构图内）；
  - 云瓣通过 `smin` 平滑融合成扎实饱满的巨型积云体，叠加零均值、Lipschitz 受限的 3D `billowNoise` 表面菜花鼓泡起伏（随 `selfTime` 持续缓慢向上翻涌），整体水平坐标严格由 `WindField` 积分推进。
- **簇包围球裁剪（晴空 0 次求值）+ 保守球体追踪**：
  - 光线先与最多 4 个簇包围球做解析求交并生成 `activeMask`；晴朗河口与草地直接跳过，**0 次 SDF 与 3D 纹理求值**；
  - 命中包围球后以保守步长系数（`0.62`）执行 Sphere Tracing（省电/标准/高分别上限 `22 / 32 / 40` 步），直接收敛到连续三维云表面，**从数学上彻底消除等距水平切片**。
- **单次命中《光·遇》云野奶油着色**：
  - 仅在命中曲面后执行 1 次着色：4-tap 四面体解析法线 + 沿同方位角压低仰角的艺术侧光太阳方向 + 2–4 步软 SDF 自阴影 + 2-tap SDF 褶皱 AO + 菜花谷底加深 + 边缘 SSS 次表面透光与克制 Fresnel 暖边；
  - 亮度范围针对 `ACESFilmicToneMapping`（`exposure: 1.25`）校准为三阶渐变（深褶皱淡天蓝/浅薰衣草蓝 → 中间暖珍珠白 → 受光奶油顶），杜绝整片死白过曝，并辅以半/四分之一分辨率 3-Pass Kawase Bloom（高阈值 `1.08`、低强度 `0.10/0.15`，省电档关闭）；
  - 云缓冲分辨率按画质设为 `55% / 75% / 100%`（高画质 100% 全分辨率直出免上采样模糊）。
- **紧致局部 Smooth-Max 飞机穿云雕刻**：
  - 路线 A、B 共用云组与当前载具接触球并集的平滑减法。B 以光栅化命中处的位置和法线校准局部距离场，沿视线求减法后的表面并用其梯度受光。主体与外侧接触球的最大半径分别为 2.1 和 1.4 个世界单位。两条路线使用相同的分载具历史轨迹，凹陷与肩部隆起随云漂移并回拢。
- **极速解析 SDF 云影 Pass**：
  - `cloudShadowFragment` 直接对活跃云簇的解析 `smin` 云瓣沿太阳射线采 4 个高度层，与可见云墙 1:1 严格对齐且 CPU/GPU 开销极低。

### 4. 恢复俯视云墙冲击构图与晴天云野地景

**方案**：
- **相机回调**：恢复 `RULES.camera` 巡航参数为 `fov: 48`, `pitch: 52`, `displayPitch: 64`, `distance: 66`, `far: 280`（`skyDome` 恢复 `420`），不再把云墙拉远变小，直接恢复原有的压迫感与 8 方向操控手感。
- **晴天云野地景**（`ShaderMaterials.ts`）：
  - 删除 `aerialPerspective` 中的近景 `valleyMist`，改回仅在视野最远边缘（`105~235`）施加极轻柔的晴空远景淡化，保证视野内每一块草地、道路和河水都清透鲜亮；
  - 保留丝绒草地暖黄绿/翠绿渐变与双色金色风吹麦浪，强化**清透浅天蓝云影**与明媚阳光草地的明暗反差；
  - 保留水面的天空色反射与太阳方向闪烁高光；
  - 保留玩家穿云时的受限光雾包裹（`cloudVeil <= 0.30`）与空腔外环隆起受光，保持 `overlayScene` 绝对可读性。
- **低面数蓬松树冠**（`VegetationField.ts`）：
  - 将树冠从 4 个 `SphereGeometry(1, 6, 4)` 精简为 **3 个低面数柔和球簇**（1 顶球 + 2 错落侧球，`SphereGeometry(1, 5, 3)`，北极顶点严格保持在 `y = 2.685`），继续使用从树冠中心外发散的柔和球面法线与平滑着色，单棵树面数减半，全场景三角面压回 `~60k` 基线水平。

## Risks / Trade-offs

- **[Risk] 单次太阳方向导数采样不如多步长距光线追踪那样能投射超长跨云瓣硬影** → Mitigation：结合预计算的宏观阴影（`columns.a` 和 `wallVolume.g`）提供大尺度云墙明暗体量，单次 3D 方向导数负责近景翻涌云泡的实时褶皱凹凸，二者互补既保立体冲击力又将 GPU 负载降到 1/10。
- **[Risk] 解析局部微移幅度过大可能让云墙看起来脱离风向晃动** → Mitigation：将微移严格限制在零均值、低频且小幅（`±1.4` 世界单位以内，远小于云瓣半径 `10~25`），视觉上仅表现为云朵表面缓慢翻滚舒展，不产生可感知的宏观漂移。
- **[Risk] 本变更此前曾修改 `battle/camera-and-view-feedback` delta 规格** → Mitigation：因恢复原版俯视构图不再改动相机规格，需移除多余的 `specs/battle/camera-and-view-feedback/spec.md` delta，并在 `tasks.md` 中新增重构纠偏与实测性能验收任务。

## Migration Plan

1. 清理不再修改的相机 delta 规格，并更新 `tasks.md` 反映俯视角云野纠偏重构任务。
2. 按设计重构 `CloudFlow.ts`、`Cloudscape.ts`、`config.ts`、`ShaderMaterials.ts`、`VegetationField.ts` 与 `eras.ts` 云野色板。
3. 更新并运行全量单元测试与构建校验。
4. 在 360×640 视口实测晴天河口、穿云墙与满载战斗的视觉对比、帧耗时和三角面预算。

### Route B · 默认移动端网格

- 使用同一组确定性云瓣作为静态融合等值面。每簇提取一张带索引网格，法线取融合距离场的梯度。褶皱遮蔽和大尺度侧光在网格生成时预计算，离开活动范围后的网格按固定上限缓存。
- 顶点使用场景时钟和三维噪声驱动翻涌与微移，并响应飞机的局部挤压，云组坐标由风场积分推进。片元按云瓣法线与太阳的夹角及烘焙透光量划分暖白受光面和冷蓝阴影，用窄半影连接两者。背光坡面按朝天程度接受环境光，边缘按厚度和噪声透出背景。
- 三档均使用世界缓冲的原生分辨率。云网格以世界深度执行硬件测试，并读取原始深度实现接触软化。云内使用受限雾化。机身和翼尖按接触距离记录随云漂移的航迹，云面沿法线退让、边缘隆起，保持玩家覆盖层可读。路线 A 可经开发验收入口对比。
