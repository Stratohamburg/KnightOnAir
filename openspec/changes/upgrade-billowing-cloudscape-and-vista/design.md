# Design

## Context

参见 `proposal.md` 的背景说明。当前实现中，体积云由 `Cloudscape`、`CloudscapeLayout`、`CloudWall` 和 `CloudFlow` 协同构成：
- 远景云依赖 512×512 2D 柱体纹理（base/top/coverage/bakedSun）+ 32³ RG `detailNoise`，缺少垂直对流与实时自阴影；
- 近景 3D 体积 `wallVolume` 仅覆盖世界坐标 `x∈[2,78], z∈[-70,50]`，范围外完全失效，且使用静态烘焙的 `voxel.g` 光学深度与 5 点盒式平滑，无法响应动态翻涌与穿云空腔；
- 光线步进（12/18/24 步）无像素抖动，云缓冲使用 `NearestFilter`；
- 巡航相机 `pitch: 52°`、`fov: 48°`、`far: 280`，视野几乎全朝地面，缺少天空地平线与云海纵深；
- 地表与水面只做线性距离雾，且 `ERAS` 仅有 4 个基础色值，未同步驱动云层与天空色板；树冠为 `flatShading` 双圆锥。

同时，项目要求：
- 保持 `src/simulation` 独立且确定性不变（所有改造严格留在 `src/rendering` 与 `src/data`）；
- 保持既有公开契约与测试语义：3 个画质档位仍遵循 `40%/50%/65%` 云缓冲比例与 `12/18/24` 采样上限；标准档 360×640 满载战斗保持 `< 150` Draw Calls 和 `< 150,000` 三角形；玩家相机居中、屏幕方向映射和目标尺寸缩放校验（`tests/controls.test.ts`）必须通过。

## Goals / Non-Goals

**Goals:**
- 在全地图任意位置提供连续、三维立体翻涌的体积云海（低空云海 + 中高空立体积云脊/云壁 + 河道开口）。
- 通过 32³ RGBA 多倍频 Worley-Perlin 3D 纹理 + 对流平流坐标扭曲 + 实时 2~3 步太阳方向多散射自阴影，让云体呈现《光·遇》式奶油暖光、通透冷影、粉末立体感与银边散射。
- 通过确定性每像素 IGN 抖动、空白区域跳过与 `LinearFilter` 深度感知上采样，在不提高步数上限的前提下消除切层感与锯齿。
- 调整巡航相机构图释放天空与远景云海纵深，同时保持轰炸高俯角切换与现有屏幕操作/居中/尺寸测试通过。
- 升级地景大气氛围：时代全链路色板（天空、云顶/云底、雾海、地表、水面）、高度雾 + 太阳方向散射、丝绒草浪、星光水面反射、蓬松软法线树冠，以及玩家穿云时的受限光雾融合。

**Non-Goals:**
- 不引入外部贴图、GLB 模型或新的第三方依赖。
- 不修改地形高度场算法、碰撞、航线或模拟层物理规则。
- 不在本变更中引入额外多 Pass 全屏后处理 Bloom 管线（可通过云顶/太阳高光与 ACES 色调映射 + 柔和大气光晕实现高通透光感，避免移动端额外多 RT 带宽压力；后续如有需要可作为独立变更增量加入）。
- 不新增大型场景地标建筑群或修改地形块数量超过移动端预算。

## Decisions

### 1. 全地图无缝三维翻涌云场（保留局部云壁增强并统一三维雕刻）

**方案**：
- 升级 `bakeCloudNoise`（或新增专用 3D 体积噪声通道）为 **32³ RGBA `Data3DTexture`**（仍保持确定性种子生成，约 128 KB）：
  - `R`：低频 Perlin-Worley 混合主体鼓包（构建饱满的大云瓣）；
  - `G`：中频 Worley 菜花隆起；
  - `B`：高频 Worley 卷边侵蚀；
  - `A`：低频连续扰动场，用于三维翻涌坐标扭曲（Curl-like Domain Warp）。
  - 为兼容现有单元测试 `tests/cloudscape.test.ts` 对 `bakeCloudNoise`（`cloudNoiseSize ** 3 * 2`）与 `bakeCloudWall` 的直接断言，保留原有 `bakeCloudNoise` / `bakeCloudWall` 的导出与确定性行为，同时新增 `bakeBillowNoise`（32³ RGBA）供三维翻涌着色器与 CPU 翻涌查询使用，并将 `wallVolume` 作为河口东岸的宏观塑形增强（同样叠加动态三维翻涌侵蚀与实时方向光阴影，不再使用静态盒式模糊掩盖细节）。
- **双层三维云结构**（均处于 `[cloudBase, cloudTop]` 区间内，河口开口同时作用于两层以保持水道畅通）：
  1. **低空云海层（`y ≈ 13 ~ 23`）**：全地图无缝平铺的低频波状云海，略低于飞行高度（`flightAltitude = 24`）并在河口和山谷上方自然开合，让玩家掠过云海时能清晰看到翻涌的立体云浪从机腹下流过、山脊与石拱从云海中探出。
  2. **中/高空立体积云脊与云塔（`y ≈ 19 ~ 96`）**：沿用并强化 `columns` 2D 宏观布局图的水平环绕平铺（`RepeatWrapping`，去除边缘 0.499 截断，让远景云海延展至远裁面），用三维 Perlin-Worley + 垂直高度剖面（圆顶平底积云轮廓）实时雕刻立体体积。
- **三维对流翻涌（Billowing）驱动**：
  - 将水平风漂移 `drift` 与自发翻涌相位 `selfTime` 解耦：
    - 宏观塑形坐标沿 `drift` 平移，并叠加慢速向上对流抬升 `vec3(0, -selfTime * riseRate, 0)`；
    - 表面菜花侵蚀坐标沿风向与垂直上升方向双倍速滚动，并利用 `A` 通道做三维域扭曲（Domain Warp），产生真实的“从内部鼓出 → 顶部舒展 → 边缘卷曲消散”的三维立体动态；
    - 零风速下仅靠 `selfTime` 仍持续翻涌，暂停时 `sceneDelta = 0` 使 `drift` 与 `selfTime` 同时冻结。

**替代方案对比**：
- *纯 3D 体积纹理覆盖全地图*：覆盖 `760×760×90` 需要巨大 3D 纹理才能保证精度，显存和初始化烘焙时间在移动端不可接受；而“2D 宏观布局图（可平铺）+ 32³ 多倍频 3D 菜花噪声实时雕刻 + 河口近景塑形”兼顾了全地图无缝与极低内存占用。

### 2. 实时多散射光照与《光·遇》式大气色板

**方案**：
- 在 `Cloudscape` 片元着色器中，对每个非零密度步进点沿太阳方向执行 **实时短距自阴影采样**（低档 1 步、标准档 2 步、高档 3 步），同时融合宏观 `columns.a` 远距遮蔽：
  - **多散射透射率**：`energy = max(exp(-sunDepth * 1.15), 0.62 * exp(-sunDepth * 0.28))`，保证云厚处依然通透明亮而非暗灰。
  - **粉末效应（Powder）**：`powder = mix(1.0, 1.0 - exp(-density * 2.4), 0.55)`，让背光面云瓣沟壑拥有清晰的三维体积凹凸。
  - **双瓣 Henyey-Greenstein 相函数**：前向强银边高光（`g = 0.72`）+ 柔和背向散射（`g = -0.22`），面向太阳方向时云边泛出奶油金晕。
  - **地面反弹光 + 三色层次**：按云内归一化高度将云底（偏亮薰衣草蓝/冰湖青 + 地表反弹光）、云腰（柔白淡青）与云顶（奶油暖白/晨曦金）混合。
- 扩展 `src/data/eras.ts` 的 `colors` 字段（保持原有 `grass`/`accent`/`water`/`haze` 不变，新增可选或完整大气色字段：`skyZenith`、`skyHorizon`、`sunTint`、`cloudLit`、`cloudShadow`、`cloudRim`、`valleyFog`），在 `Renderer` 切换时代时统一更新 `skyDome`、`cloudscape`、`terrainMat`、`water` 与雾效。
  - 萌芽期（黎明草甸）：晨岛破晓粉金暖云 + 淡紫蓝云底；
  - 一战（堑壕天空）：雨林/晨雾苍青云隙 + 柔和琥珀暖光；
  - 二战（铁翼海峡）：霞谷日落暖橘金云 + 靛紫云底；
  - 初代喷气（翡翠海岸）：云野澄澈天蓝 + 奶油蓬松白云 + 冰蓝通透云底。

### 3. 消除步进切片与平滑深度上采样

**方案**：
- 在 `cloudFragment` 引入 **确定性 Interleaved Gradient Noise（IGN）** 对每像素步进起点做 `[0, stride)` 偏移（纯屏幕坐标函数，暂停时完全静止不闪烁），消除 12/18/24 步下的等距水平切片条纹。
- 在空域采用粗步进/高度包络跳过，仅在命中云层包络或河口近景云壁时精细采样，并允许在 `transmittance < 0.02` 时提前退出。
- 将 `Cloudscape` 的 `buffer` 滤波从 `NearestFilter` 升级为 `LinearFilter`，配合 `compositeFragment` 现有的深度感知 2×2 双边上采样，消除像素块锯齿并保持世界物体边缘不渗色。

### 4. 巡航纵深构图与玩家穿云融合

**方案**：
- 调整 `RULES.camera` 巡航参数：
  - 保留巡航俯角 `pitch: 52°`（受 `screen-relative orientation` 对角线屏幕方向一致性校验 `dot > 0.98` 的几何下限约束），将 `fov` 从 `48°` 拓宽至 `62°`、`distance` 从 `66` 贴近至 `48`、`far` 从 `280` 延展至 `460`（`skyDome` 半径同步调整为 `440`）。
  - 验证数学约束：
    - 俯角 `52°`、垂直半视角 `31°` → 画面上沿仰角从 `-28°` 抬升至 `-21°`，且相机高度从 `76` 降低到 `61.8`（落入高耸云塔 `y = 20..96` 的腰部高度带），在保持机体屏幕尺寸舒展的同时显著增强三维体积云视差、低空云海远景覆盖与纵深；
    - 仍通过 `camera.lookAt(x, RULES.flightAltitude, z)` 确保玩家在所有宽高比与过渡混合系数下投影精确位于 `(0, 0)`，且所有 8 方向屏幕相对操控保持 `dot > 0.98`；
    - `tests/controls.test.ts` 中对巡航模式目标屏幕宽度 `<= 0.7 * reference` 的检查仍严格满足（`~0.60~0.64 <= 0.70`）；
    - 轰炸模式保留高俯角（`pitch: 74°`, `fov: 34°`, `distance: 74`），形成“巡航开阔云海 ↔ 轰炸俯视锁敌”的强烈视效层次。
- 扩大 `TerrainChunks` 视野覆盖与雾距匹配：`scene.fog` 与 `aerialPerspective` 远距从 `220/240` 平滑延展以匹配 `far = 460` 与开阔巡航视角（若 chunk 网格保持 5×5，需注意远景截断边界在雾海中柔和消融，把雾完全消融距离控制在 chunk 覆盖半径 `~200` 之内，避免看到地形网格硬边！）。
  - 关键边界检查：`TERRAIN.chunk = 80, chunkRadius = 2` 覆盖 `±200`（5×5 块）。因此地形高度雾与大气透视在 `155~198` 之间平滑融入地平线雾海色，而云层（无 200 截断限制）延展至 `420` 与 `skyDome` 无缝衔接！这样既不增加任何地形 Draw Call/三角形，又能让玩家看到一望无际的远方云海与天空。
- **玩家穿云融合**：在 `aircraftMaterial` 增加 `cloudVeil`（`0~1`，由 `cloudscape.cameraDensity` 与玩家位置处云密度平滑计算并上限 `0.32`）和 `cloudTint` uniform，穿云时给机体叠加柔和的云雾边缘光晕与轻微色彩包裹，告别贴纸割裂感，同时玩家轮廓、弹道和瞄准环保持高对比度清晰可读。
- **玩家空腔边缘隆起**：在 `sampleCloud` 中，玩家周围空腔外环（`bodyInfluence` 衰减带）略微提升密度（`+ridgePush`），配合实时太阳自阴影，飞机穿云时能在翼尖周围看到被推开并被阳光照亮的翻涌云浪。

### 5. 地景与植被的《光·遇》式氛围升级

**方案**：
- **丝绒化地表与高度雾**（`ShaderMaterials.ts`）：
  - 减弱高频杂乱噪点对比度，强化低频暖阳嫩绿与背光清透蓝绿的绘本色温对比；
  - 草浪升级为“波峰暖金高光 + 波谷清冷青绿”的双色流动色带，辅以柔和视线掠角丝绒边缘光（Velvet Fresnel）；
  - `aerialPerspective` 升级为 **指数高度雾 + 太阳方向暖金内散射**：低谷与河谷凝聚乳白/淡青雾海，朝向太阳方向叠加柔和的温暖散射光晕，使地形在 `155~198` 范围自然融进云海与天空。
- **水面质感**（`ShaderMaterials.ts`）：
  - 保留既有风场驱动波纹语义，增强菲涅尔天空渐变反射（接入时代 `skyHorizon`/`skyZenith`），叠加更清脆柔和的太阳方向细碎星光闪烁（Sparkle Specular）。
- **蓬松绘本树冠**（`VegetationField.ts`）：
  - 将 `treeGeometry` 的双圆锥替换为由 3~4 个错落低模球体（`IcosahedronGeometry(r, 1)`）融合而成的蓬松树冠 + 细树干，总高度保持 `2.685`（满足 `tests/vegetation.test.ts` 对 `bendWeight` 归一化高度 `2.685` 的断言），并重新计算**从树冠团块中心向外发散的柔和球面法线**、关闭 `flatShading`，让树冠在阳光下呈现《光·遇》/吉卜力般的绵软渐变受光，同时每棵树保持低面数（~160 三角形，9 块地合计仍在预算内）。

## Risks / Trade-offs

- **[Risk] 实时方向光自阴影采样会增加体积云片元着色器纹理查询次数** → Mitigation：按画质档位分级（low: 1 步太阳采样, standard: 2 步, high: 3 步），在空白区域提前跳过太阳采样，并利用 `transmittance < 0.02` 早退；在 360×640 验收场景实测帧时间与 `rayMarchCpuMs`，确保流畅运行。
- **[Risk] 放缓巡航相机俯角可能暴露地形 5×5 分块（`±200`）的远处边缘** → Mitigation：将 `aerialPerspective` 雾消融终点精确锚定在 `190` 附近，并与地平线天空色及低空云海对齐，使地形边缘在到达区块边界前完全隐入雾海，而云海继续延伸至远景天际线。
- **[Risk] 放缓巡航俯角可能破坏 `tests/controls.test.ts` 的目标屏幕尺寸比值校验或方向一致性** → Mitigation：严格保持 `camera.lookAt(x, RULES.flightAltitude, z)` 与 `yaw = 0`（不改变屏幕前方语义），通过计算和运行 `npm test` 验证巡航/轰炸两模式均满足 `<= 0.7` 的尺度比例断言。
- **[Risk] 修改 `CloudscapeLayout` / `CloudFlow` / `VegetationField` 可能破坏已有确定性单元测试** → Mitigation：保留 `bakeCloudNoise`、`bakeCloudWall`、`cloudWallWeight`、`cloudMorph`、`morphWallDensity` 及 `treeGeometry` 高度 `2.685` 的既有接口与契约，新增扩展测试覆盖全地图翻涌云、时代色板联动和巡航视野。

## Migration Plan

1. 先扩展时代大气色板与云场核心模块（32³ RGBA 翻涌噪声、全地图双层三维云场、实时多散射自阴影、IGN 抖动与平滑上采样）。
2. 更新巡航相机构图与玩家穿云融合反馈。
3. 升级地表丝绒材质、高度雾与太阳散射、水面反射高光及蓬松软法线树冠。
4. 运行全量单元测试与 TypeScript 构建校验，并在本地开发服务器启动 `/?environmentTest=1&scene=cloudscape` 与 `scene=battle` 检查视觉效果、Draw Calls、三角形与性能指标。
5. 若某项视觉或性能参数需要微调，全部参数均集中在 `config.ts`、`eras.ts`、`CloudFlow.ts` 和着色器常量中，可快速独立回退或调参。
