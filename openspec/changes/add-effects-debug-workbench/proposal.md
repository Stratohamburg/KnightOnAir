# Proposal

## Why

原型校验台可以核对飞机外形，但目前很难在同一架飞机、同一段飞行中反复观察特效。例如机翼中段的宽淡拖尾在 S 弯换向处是否断开，需要同时看到挂点、姿态和已经飞过的轨迹。

## What Changes

- 沿用展台「校验」入口，顶部常驻「原型」「特效」页签。既有原型直达链接和机型选择可继续使用。
- 「特效库」可逐项触发、停止和重播现有特效。「机型表现」使用真实模型、部件和挂点，可单独或组合观察气流、发动机、破损及开火。
- 所有配置从相应库按 ID 读取。调试台仅保留当次选择、播放进度和预览实例，库中新增的机型或现有类型的效果变体可直接进入预览。
- 平飞、S 弯、持续左转或右转可以分别搭配低速、巡航及机型支持的加力。用独立轻量空间、固定步播放和可复现的输入进行检查，全程不加载游戏场景。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `rendering/runtime-content-library` 补充面向预览的目录读取与触发条件，使预览和实际运行共用同一份内容定义。

已有的调试台主规格覆盖两种预览、页签切换和视觉验收，本变更负责实现其全部 7 项要求和 13 个场景。[调试台主规格](../../specs/app/debug-workbench/spec.md)

## Impact

涉及调试入口与原型视图、机型与特效库、固定步飞行输入和预览资源的释放。复用飞机工厂、战斗特效批次和现有调试可见性规则。验收覆盖窄屏导航、库配置变更、重复播放和游戏场景隔离。
