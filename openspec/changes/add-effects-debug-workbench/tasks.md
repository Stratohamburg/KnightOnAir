# Tasks

## 1. 内容库与目录

- [x] 1.1 由机型配置、原型档案及其现有映射生成只读目录。用无档案机型、无模型原型和空目录验证各页可用状态。
- [x] 1.2 在特效定义旁补齐预览所需的名称、触发条件与播放方式。用库内新增变体、修改参数、移除条目的测试确认界面无需登记；缺失引用可定位到 ID 和动作。

## 2. 校验入口与页签

- [x] 2.1 在展台「校验」和原型直达入口接入常驻页签。核对调试可见性、指定 frame 链接、原型三视图及模型切换、返回展台，并在 360 × 640 展开面板验证两个页签始终可点。
- [x] 2.2 按库映射在页签间传递选择，保留各自的观察状态。分别验证正常映射与缺失映射，连切两次后选中机型和暂停时刻均可恢复。

## 3. 独立预览与播放

- [x] 3.1 实现独立相机、基础光照、中性背景及按需加载的参考挂点或靶面。遍历现有特效，在库预览中验证瞬时效果重播、停止持续发射后的自然消散，以及重置后清空。
- [x] 3.2 为预览接入固定步时钟、暂停、单步、慢放及种子与输入重播。重复播放并在同一步比较姿态和发射事件，验证隐藏页签不会继续推进。
- [x] 3.3 接入明暗背景、画质档、挂点标记及整机的跟随和固定镜头。用同一暂停帧验证观察设置切换后仍能定位相同的效果起点。

## 4. 机型表现

- [x] 4.1 用飞机工厂和固定步飞行输入接入平飞、S 弯、持续左右转及低速、巡航、加力预设。验证巡航平飞默认值、机型限制，以及转弯中切换动力时的连续轨迹。
- [x] 4.2 支持按类单显和组合观察。用 Dr.I 检查 S 弯换向时翼中宽淡带的连续性与独立翼尖线，用 Ho 229 检查单侧发动机故障及正常侧喷流。
- [x] 4.3 将开火和选点损伤接到运行时特效。用倾侧齐射验证逐管枪焰和抛壳，用同翼双洞验证倾侧、维修、脱落及换机后的清理。

## 5. 集成验收

- [x] 5.1 从展台和直达链接遍历两种预览，反复换机、切页和退出。检查游戏场景及地景资源加载记录、活动预览时钟、实例租约和玩家存档，验证会话隔离。
- [x] 5.2 运行现有展台、飞行动力学、机型特效与战斗特效回归测试，逐项记录调试台主规格 13 个场景及内容库增量场景的结果。
