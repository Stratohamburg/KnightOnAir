# Design

## Context

`ReferenceApp` 目前在右栏的一次渲染中重建机型选择、页签和资料卡，左栏独立承载图板与模型。参考索引合并主体档案和航空萌芽期附录。模型注册表通过 `frameId` 查找几何证据和图板审核结果，现有的 `?reference=1&frame=…` 入口也使用该标识。福克 Dr.I 图板已读取独立测量数据，起落架等部分轮廓坐标仍写在 SVG 模板中。

[当前页面](../../../src/app/ReferenceApp.ts) · [资料索引](../../../src/data/aircraftReferences.ts) · [模型注册表](../../../src/content/3d/aircraftModels.ts) · [福克图板](../../../src/content/2d/fokkerReviewPlate.ts)

## Goals / Non-Goals

**Goals**

- 一份原型档案即可进入目录并渲染已有资料，抽象图板与模型可在各自资料齐备后接入。
- 同一变体的证据、已核定数据与 3D 注册可以互相追溯。已有资料、审核状态和链接可迁移复用。

**Non-Goals**

- 新原型考证、参考图补录、几何重测、出击机体配置及改装规则调整。

## Decisions

### 以原型档案作为选机来源

在 `src/data/aircraft-references/` 维护类型定义、小型索引和逐变体档案。档案记录稳定原型 ID、名称、历史时代键与标签所需信息、变体、简介、资料索引和已有结构说明。与游戏机体、既有图板或模型注册的关联通过相应 ID 表达，关联按实际资料选填。时代分组使用结构化历史时代键，同组沿用档案顺序。将目前 6 份主体档案和 10 份航空萌芽期档案迁入。

保留 `frame` 查询的既有值作为解析别名。有效链接进入目标原型并将当前目录项滚入可见区。缺省或未知值回退到现有默认机型福克 Dr.I。程序化模型注册表可继续通过机体 ID 解析同一份档案的证据。目录的纳入条件由历史档案表达，游戏机体清单负责游戏内的机体配置。

### 将原图、测量记录和模型参数落在可复用文件中

- 原图沿用 `src/assets/reference/<原型 ID>/` 目录约定。档案引用现有本地资源或外链，随资料保存来源页、变体、视图覆盖、署名和核对状态。资料尚未录入时，档案可保留已有项目。
- 图板读数沿用 `src/data/` 的逐机型数据模块，保存图纸单位与基准、各视图轮廓与定位点、左右读数、适用容差和审核差异。把图板模板中属于机型的坐标和轮廓提取到对应数据模块，渲染组件负责 SVG 结构和样式。
- 3D 装配器继续通过现有注册表读取审核通过的变体生成参数。读数到生成参数的单位换算、派生尺寸与站位集中在对应数据模块。原始读数和修正结果以可追溯的方式保存，模型所用审核状态沿用该变体的证据记录。
- 使用现有构建流程加载类型化本地数据。新增仅供校验的原型时，录入档案及索引即可显示已有资料。

### 在页面中独立管理目录、资料和预览

宽屏保留同一个纵向目录滚动容器，并让右侧详情自行滚动。换机时更新选中项与详情，同时重置详情滚动、预览页签、相机与部件高亮。窄屏把同一目录放入左侧抽屉，选中后关闭，详情获得完整横向空间。默认断点由现有响应式样式在实现时确定。

将「2D 抽象三视图」和「3D 模型」放在同一预览区上方。查到图板时即可展示，调用现有模型解析判断当前变体是否可生成，并把具体原因交给预览区。满足生成条件的变体初始即可选择 3D 页签，首次选择时创建模型预览。3D 页签是预览入口，当前机型来回切页签复用预览实例，2D 页签暂停 3D 绘制。换机或离开时释放上一预览及其内容租约。3D 视图沿用正交检查与环绕入口，拖动范围限定在模型区域。

下方沿用资料卡组件，按参考原稿、照片、结构校验、审核记录、改装参考排列已有内容。中心线与模块节点继续驱动当前模型的高亮，Ho 229 V2 的翼段试装按钮随可用模型显示在 3D 工具区，并通过现有临时预览构型执行。

## Risks / Trade-offs

- 拆分档案时，模型注册表可能找错变体。迁移时核对原型 ID 与既有查找别名，复跑福克、Ho 229、喷火、零式和流星的现有模型检查。
- 各图板模板使用不同单位和取点方式。按变体迁移字段，逐张对照原页面中的轮廓、位置、来源和待审提示。
- 目录与详情双滚动可能和模型拖动争用触控。桌面验证独立滚动，竖屏验证目录触控、详情滚动和模型环绕。

## Migration Plan

先迁移档案与兼容别名，并将模板中的机型数据移入相应模块。再接入双栏、两种预览和资料区，最后用现有档案、直达链接及模型回归验证迁移结果。参考来源、本地素材和测量记录随代码从同一版本交付，可通过回退本变更恢复旧页面。
