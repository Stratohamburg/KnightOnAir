# Proposal

## Why

原型校验台的横向机型列表和参考资料共用一栏，原型增加后难以连续浏览。现有页签同时承担预览切换和资料卡操作，参考档案集中存放，部分机型的轮廓和定位参数仍写在图板模板中。

## What Changes

- 左侧提供独立纵向滚动的历史原型目录，每项显示机型名称和历史时代。目录保留已入档但待补图板或待审核的原型，排除没有参考记录的旧架空机体。
- 右侧详情顶部提供「2D 抽象三视图」与「3D 模型」两个页签。切换机型时回到 2D，并按现有的变体审核流程决定是否启用 3D。
- 将参考原稿、照片、结构校验、审核记录和改装参考放在预览下方。保留中心线节点与模型部件联动，将 Ho 229 V2 的翼段试装入口放进 3D 工具区。
- 按原型维护可索引的参考档案，独立存放原始素材、变体图板读数和已审核生成参数。页面按记录渲染目录、校验资料和预览状态。

## Capabilities

### New Capabilities

- `app/aircraft-reference-lab` 定义原型目录的收录规则、时代与选机、双页签预览、变体资料和详情交互。

### Modified Capabilities

## Impact

涉及 `ReferenceApp`、校验台样式、原型数据索引、参考图板组件和飞机模型注册表的资料查询。原型 ID 支持独立入档及现有 `frame` 链接。模型预览继续通过现有模型注册表、机体工厂与资源释放流程运行。
