# Design

## Context

当前项目使用确定性 CPU 高度场、5×5 流式地形块、共享地形 shader、道路与水面遮罩以及独立的风动植被批次。玩家镜头固定为竖屏俯视角，地平线和屏幕外远景不属于可见体验预算。提案中的目标和范围见 [proposal.md](proposal.md)，行为约束见本变更下的四份规格增量。

现有高度场已经能返回最终地表高度、坡度、水面、岸线和道路状态。地形材质主要通过世界坐标噪声、坡度和水岸高度混合草、道路、沙地和岩石颜色，草地颜色还会随场景时间和风向形成连续波纹。TerrainChunks、TerrainLandmarks 和 VegetationField 各自管理部分地面内容，房屋和聚落没有独立的地面装饰目录。

## Goals / Non-Goals

**Goals**

- 在当前俯视视口内建立连续的山脉、丘陵、山谷、低地和水岸关系。
- 让最终地表高度成为材质分层、景物分布和贴地查询的共同输入。
- 使用清晰的低频色块表达云野式明亮草甸、花甸、湿地、山肩和裸岩。
- 取消地形基础颜色的时间驱动波纹，把风动留给植物顶点、树冠和水面。
- 在可见地形范围内提高房屋、花簇、灌木、岩石和小型地标密度。
- 通过视口优先的实例批次和共享资源保持既有移动端预算。

**Non-Goals**

- 不增加屏幕外远景山脉、地平线背景或独立远景环。
- 不改变玩家输入体系、自动飞行高度、碰撞规则或地面路线运动规则。
- 不让装饰性房屋和景物自动成为战斗目标，战斗目标继续由战斗内容配置声明。
- 不引入外部图片贴图、地形编辑器或运行时可破坏地形。

## Decisions

### 视口内的宏观地貌使用同一高度函数

在 `Terrain.ts` 中把当前的低频起伏、局部 landform 和山脊抬升整理成可组合的宏观地貌通道。通道输出连续高度和派生的山脊、谷地、丘陵权重。河道、水岸和路线压平继续在最终高度阶段应用。

宏观通道按以下顺序组合。

```text
山脉中心线、峰顶、鞍部和盆地
  -> 各向异性脊线场与 ridged multifractal
  -> 主谷、支谷、沟壑和层级排水网络
  -> 谷地横截面、河床、冲积扇和湿地
  -> 有限热侵蚀与缓存的液压侵蚀权重
  -> 低频残余噪波
```

脊线和谷线使用确定性控制点或曲线距离场。噪波用于偏移边界和补充尺度细节，不承担山脉走向、谷网层级或路线空间的唯一决定权。峰顶、鞍部和盆地作为可查询的派生地貌特征，供材质、景物和路线选择读取。

选择连续通道是因为当前镜头只看到地形块内部，山脉需要通过可玩地表本身形成轮廓。单独添加远景网格会把预算投入屏幕外区域，且无法改善玩家脚下的山谷、坡面和海拔材质关系。

高度函数仍然只依赖种子和世界坐标。路线、炸弹、地面单位、阴影、植被和特效继续读取 `surfaceHeight()`。地形块边界使用同一世界坐标采样，因此跨块重建不产生海拔跳变。

### 结构化谷地和生成期侵蚀

河流与谷地共享层级排水网络。主谷提供较宽的谷底和沉积区，支谷提供坡面切口，低等级沟壑提供视口内的局部剧烈转折。谷线横截面控制谷底宽度、侧壁坡度、沟槽深度和冲积扇扩散范围。

地形块创建时可以运行固定迭代次数的热侵蚀规则，处理超过临界坡度的面片并生成坡脚碎石权重。液压侵蚀使用有限的生成期或离线缓存，输出沟槽、流量和沉积权重。基础高度在运行时保持可查询和稳定，侵蚀结果不会在每帧改变路线、碰撞或炸弹落点。

完整实时侵蚀需要维护跨块水量、沉积物和可变高度状态，会增加帧时间峰值、暂停与回放状态、跨块接缝和确定性测试成本。GAN 和扩散模型需要训练数据、模型权重、推理运行库、平铺接缝处理和条件约束，难以直接保证路线、谷底宽度、地面单位空间和固定种子复现。三者保留为离线研究或候选高度图生成工具，候选结果进入运行时前仍需经过结构化地形管线。详细记录见 [程序化地形研究](../../../docs/PROCEDURAL_TERRAIN_RESEARCH.md)。

### 海拔信息以纯数据通道传递

`TerrainSample` 增加海拔相关的连续权重或分层数据，至少能区分低地、丘陵、山肩和高坡，并保留水面、岸线、道路和坡度信息。模拟层只返回数字和枚举，不引用 Three.js。

渲染地形网格在构建时写入海拔和地貌属性。shader 使用这些属性和固定世界坐标噪声生成材质颜色。材质权重采用连续过渡，让海拔变化呈现为草皮到岩面的自然带状关系，水面、岸线和道路拥有更高优先级。

选择 CPU 派生属性加 shader 混合，是因为只在地形块创建时采样一次，能让材质、植被和景物共享完全相同的海拔语义。仅在 shader 中重新推导海拔会造成模拟层、植被布局和材质边界使用不同判定。为每种材质创建独立网格会增加绘制次数并破坏视口密度目标。

### 地面材质采用静态清晰色块

地形基础颜色移除 `sceneTime`、`windDirection` 和 `windGust` 驱动的连续波纹。保留低频固定色块、海拔过渡、坡度明暗、云影和太阳方向。地面颜色变化必须锚定世界坐标，暂停或改变风向不能移动山脊和草甸边界。

草甸、花甸、湿地、沙滩、山肩草皮和裸岩使用共享材质中的颜色角色和权重。花色和植被颜色通过实例属性或实例颜色表达，不把每个花簇拆成独立材质。水面继续保留风向波纹，因为水面波纹属于水面材质，不会覆盖陆地地貌轮廓。

### 视口优先的地形块和景物布局

继续使用当前地形块流式结构，增加以相机视锥、玩家位置和地形距离计算的细节优先级。当前视口以及视口前方的地形块使用高密度景物和完整材质通道。侧后方和视口外的活动块保留基础地形轮廓，降低房屋、植被、岩石和局部材质细节。

景物布局使用世界坐标、地貌权重和固定种子生成。房屋、聚落、岩石、花簇、灌木、芦苇和小型地标都拥有稳定的内容 ID 与类别规则。布局查询必须拒绝水面、道路中心、过陡坡面和路线设施占用区域。相同世界坐标重新生成时，景物的位置、朝向、尺度、颜色和动画相位保持一致。

视口密度通过实例批次和共享原型提高。重复房屋使用合并几何或实例矩阵，重复岩石和植物使用共享几何、材质和实例属性。所有可复用三维内容通过 ContentCatalog 或等效的内容 ID 目录取得，离开场景时释放实例持有的租约。装饰对象不直接写入模拟状态。

### 海拔驱动的景物分布

低地优先布置花甸、湿地草和芦苇。丘陵布置草簇、灌木和少量房屋。山肩布置断续草皮和岩石。高坡降低植物密度并提高裸岩比例。房屋和聚落只出现在低地、缓坡和路线附近的可放置区域，使用与地貌色板一致的浅色屋顶、暖色墙面和青灰阴影。

选择按海拔和地貌分布景物，是为了让地形高度同时承担空间辨识和内容组织。只提高全局随机密度会产生均匀噪点，无法让玩家理解谷地、丘陵和山肩的关系。

### 风场只驱动独立可动内容

`VegetationField` 继续使用共享风场时间、方向和阵风驱动草簇与树冠顶点。地面材质不再读取风场驱动的颜色波纹。水面保留现有风向波纹和统一时钟语义。暂停时所有动态内容冻结，静态地表始终保持相同颜色和边界。

### 画质预算优先保证可见地貌

标准档继续以 360×640 视口低于 150 次绘制和 150,000 三角形为总门槛。地形诊断增加可见地形块、可见装饰实例、房屋实例、材质通道和地形三角形统计。省电档优先减少视口外装饰、远离视锥的房屋细节、岩石数量和局部材质采样，再降低视口内的次要细节。主要地貌颜色、山脊轮廓、河岸、路线和关键地标保持可读。

选择按视口分配预算，是因为项目文档将固定俯视镜头的视野内容设为首要目标。把预算平均分配给整个 5×5 地形范围会减少玩家实际看到的房屋、植物和地表材质密度。

侵蚀计算不参与每帧预算。运行时只读取地形块生成阶段缓存的高度派生数据和侵蚀权重。若局部液压侵蚀试验超出生成时间预算，优先保留山脉骨架、谷地横截面和热侵蚀，降低液压迭代次数或改用固定遮罩。

### 验收入口和回归方式

环境验收增加固定种子下的低地、丘陵、高坡、山谷和水岸镜头位置，并分别测试云开启、云关闭、云影关闭和暂停。验收图像检查地貌轮廓、海拔颜色、房屋与景物密度、地面波纹消失和近中景清晰度。

自动测试覆盖同种子海拔权重、跨地形块连续性、景物确定性、景物贴地、路线与水岸优先级和画质切换后的资源稳定性。现有路线、水面、炸弹落点、植被根部和战斗地面单位测试继续作为回归基础。

## Risks / Trade-offs

- [Risk] 视口内高密度房屋与景物可能增加绘制次数。→ 使用内容 ID、共享几何、实例批次和视锥优先级，诊断中单独记录可见实例与地形预算。
- [Risk] 海拔材质带可能形成明显色阶。→ 使用连续权重和低频区域混合，并在固定俯视截图中校准过渡宽度。
- [Risk] 增强山脉高度可能让路线和地面物体贴地异常。→ 继续以最终 `surfaceHeight()` 和路线高程为唯一放置依据，在路线周围保留压平与桥面规则。
- [Risk] 移除地面波纹后草地可能缺少动态感。→ 保留草簇、树冠和水面的风动，并用静态明暗与花簇分布表达地面变化。
- [Risk] 云影和天气雾仍可能降低地面清晰度。→ 把近中景的地面色块与云影分开调节，并按晴天、过云和小雨固定镜头验收。
- [Risk] 地形块重建时高密度装饰出现闪烁。→ 复用确定性布局缓存，按块生命周期管理实例矩阵，跨边界优先保留已存在世界坐标的实例。

## Migration Plan

1. 先扩展纯数据高度采样和海拔权重，补充确定性、范围和跨块连续性测试。
2. 加入山脉中心线、峰顶、鞍部、盆地、层级谷线和排水网络，补充脊线连续性、谷网层级和跨块曲率测试。
3. 为地形网格增加海拔与地貌属性，重做静态清晰材质并删除基础地形颜色波纹。
4. 在地形块生成阶段加入有限热侵蚀和可缓存液压侵蚀权重，验证坡脚、沟壑、沉积和生成耗时。
5. 建立房屋、聚落、岩石、花簇、灌木和湿地植物的内容 ID 与共享实例原型。
6. 将景物布局接入地形块和视口优先级，验证相同世界坐标跨块重建后保持一致。
7. 调整三档画质与诊断，确认标准档总预算和省电档降级顺序。
8. 运行环境截图、暂停、云开关、跨块和完整战斗回归。

实现期间若新材质或景物批次超出预算，可以先降低视口外实例和次要材质采样，保留视口内主要地貌。高度采样、路线查询和战斗地面语义不需要迁移存档字段。
