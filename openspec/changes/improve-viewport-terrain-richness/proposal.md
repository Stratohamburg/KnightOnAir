# Proposal

## Why

当前俯视战斗镜头已经拥有确定性地形高度、河流、路线和基础植被，但视口内的地面主要读成一片模糊的绿色草坡。地面颜色波纹覆盖了山脊与谷地结构，海拔没有形成稳定的材质和景物层级，房屋、岩石、花甸与湿地景物也不足以支撑云野风格的清新空间感。

本变更把质量集中到固定俯视镜头实际可见的地形范围，让视口内的山脉、丘陵、谷地、草甸、水岸、房屋和地标形成清楚的层次，同时保持移动端的有界渲染预算。

## What Changes

- 重整确定性高度场，在当前视口内生成连续山脉、丘陵、山谷和低地，保留统一的最终地表高度查询。
- 将宏观高度场分为山脉骨架、脊线、峰顶、鞍部、谷地和低频残余噪波，避免由各向同性噪波单独决定地貌结构。
- 使用层级排水网络表达主谷、支谷、沟壑、汇流区和冲积扇，让河道与山谷拥有同一套空间关系。
- 使用生成期有限热侵蚀与可缓存液压侵蚀权重处理过陡坡、碎石坡、冲刷沟槽和沉积区域。
- 增加随海拔变化的地表材质权重，让低地草甸、丘陵花甸、山肩草皮、高坡裸岩、湿地与沙滩具有稳定的颜色层级。
- 移除整片地形上的时间驱动正弦波纹和移动草地明暗带，保留低频静态色块与独立植被的风动表现。
- 增加视口内的房屋、聚落、花簇、灌木、湿地植物、裸岩和小型地标密度，全部使用确定性布局并贴合最终地表。
- 按固定俯视镜头集中质量，近中景保持清晰、明快和通透，视口外区域降低采样与装饰密度。
- 让三档画质控制地形细节、景物密度、材质采样和阴影成本，继续满足标准档 360×640 视口的绘制与三角形预算。
- 增加固定种子下的地形、海拔材质、景物密度、暂停、跨地块和视口截图验收。
- 记录完整实时侵蚀、GAN 和扩散模型的研究边界。它们保留在离线分析和候选地形试验中，不进入当前浏览器运行时生成路径。

## Capabilities

### New Capabilities

无。本变更扩展现有地形和环境能力。

### Modified Capabilities

- `world/terrain-and-routes`: 增加当前视口所需的连续山脉、丘陵、谷地和海拔分层采样语义。
- `rendering/terrain-rendering`: 增加视口内多层地貌、海拔材质、清晰地表和高密度地面景物表现。
- `rendering/wind-driven-vegetation`: 增加按海拔和地貌区域分布的花甸、灌木、湿地植物与岩石实例规则。
- `rendering/quality-and-performance`: 增加视口优先的地形细节、景物密度和三档质量预算要求。

## Impact

涉及 `src/simulation/Terrain.ts`、`src/rendering/TerrainChunks.ts`、`src/rendering/ShaderMaterials.ts`、`src/rendering/TerrainLandmarks.ts`、`src/rendering/VegetationField.ts`、地面景物内容定义、画质配置、环境验收入口和相关测试。地面高度、路线高程、炸弹落点、地面单位、植被贴地和水岸查询继续共享同一确定性地表数据。实现需要沿用运行时内容库的共享几何、材质和实例批次约束。

研究记录保存在 [程序化地形研究](../../../docs/PROCEDURAL_TERRAIN_RESEARCH.md)。实时侵蚀、GAN 和扩散模型的离线结果可以作为候选高度场或统计对照输入，运行时仍需要经过固定种子、跨块连续、路线可控和预算有界的结构化地形管线。
