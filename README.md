# Knight on Air · 云端骑士

移动端竖屏、右手单手操作的程序化 3D 飞行游戏。使用 **TypeScript + Three.js + Vite**，包含 M0–M3 的机库、战斗、局内改装、锁定导弹、对地轰炸和程序化表现。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端给出的本地地址，默认是 `http://localhost:5173`。同一局域网的手机可通过终端显示的 Network 地址访问。推荐竖屏，设计尺寸为 360×640 至 430×932；电脑提供侧栏和键盘辅助操作。低于 640px 高度的窗口可滚动查看完整界面。

```sh
npm test          # 屏幕方向操控、模拟、成长、存档与17 架机体的 5 分钟耐久测试
npm run check    # 严格 TypeScript 检查
npm run build    # 检查并生成 dist/
npm run preview  # 预览生产构建
```

`dist/` 可以部署到静态网站服务，资源路径支持子目录。运行时不请求外部模型、字体、贴图或音效。

## 操作

| 操作           | 手机                             | 电脑          |
| -------------- | -------------------------------- | ------------- |
| 航向与油门     | 拖动中央摇杆；距离越远，油门越大 | WASD / 方向键 |
| 巡航、恢复能量 | 松开摇杆                         | 松开方向键    |
| 自动开火       | 把敌机带入机体火线               | 同左          |
| 武器方向       | 武器沿挂点方向发射，靠转向和提前量命中 | 同左       |
| 改装升级       | 升级按钮亮起后点击，三选一       | U             |
| 切换轰炸       | 控制区右上开关                   | B             |
| 投弹           | 松杆稳定准心，绿色时点击投弹     | 空格          |
| 暂停 / 继续    | 右上暂停按钮                     | P / Esc       |

触控摇杆的内圈控制普通油门，拉出内圈进入加力区。键盘用方向键配合 Shift。普通油门不消耗加力储备，加力耗尽后回充到 8 点并松开外圈输入才能再次触发。

升级次数可以累积。小修理包和大修理包按机身、发动机、机翼和挂点的顺序修复仍在机体上的部件。投射物命中整机轮廓时优先扣除命中部件的生命，余量由其余部件均摊。禁用部件仍覆盖原有区域，可脱落翼尖会从轮廓中移除。升级、暂停或帮助与设置面板会暂停战斗。选择部件后恢复此前的空战或轰炸模式。页面失焦或进入后台也会暂停，返回后由玩家继续。

空战时显示完整双圈摇杆，外圈半径为普通区的 1.4 倍。开启轰炸后收起加力圈，显示投弹按钮，普通圈用于最高 45% 的微调油门。玩家和敌机都在世界高度 24 的空战层飞行，炸弹落到实际地表。战斗镜头跟随玩家并对准战斗画面中央，转向和速度均有惯性。

转弯使用简化协调转弯模型：速度和转弯需求决定目标倾角，动力、翼载与载荷限制倾角，质量和翼展决定滚转惯量，实际倾角再影响转弯速度。轻型强动力机在急弯时可接近 90°，重型机倾角更小、进入侧倾更慢；改装与发动机/机翼损伤也会影响操控。

## 已实现的内容

- 机库的持续飞行场景、五入口导航、装备预览和独立的实际装备状态；商店与两个预留入口按设计提供占位页。
- 机库按萌芽期、一战、二战、初代喷气分组，达到机体要求的单局积分后在结算解锁。出击页默认选择第 01 关「黎明草甸」，该关驾驶福克 Dr.I。通过「选关」切换航线，第 02 至第 04 关使用当前装备机体。
- 转向惯性、加速与能量、滑行、左右重量差、边界回转、风场漂移和轰炸微调。
- 机炮、双翼机枪、重机枪、独立炮塔、火箭、锁定导弹和三类炸弹。弹道支持穿透、弹射、齐射、散射、爆炸、制导和伴随制导等配置字段；buff 接口支持燃烧、减速和破甲。
- 战斗导演按时代和局内阶段选择敌群。空中单位避让、护航和拦截，车队、列车和船只沿路线行驶。开场、普通波次、精英和增援共用生成预算和屏外重试。
- 金币吸附、经验溢出、等级与延后升级、连击、三选一合法候选池、23 个升级配置。候选有收益、代价、前后数值比较和部件位置预览。
- 部件级玩家命中、损坏着色、冒烟与火焰、发动机减效、武器失效、维修和结构碰撞变化。
- 玩家武器沿实体挂点方向发射，弹道不替玩家选择目标；敌方锁定武器仍有蓝 / 黄 / 红锁定反馈、失锁衰减和预测制导。
- 雷达开火告警、屏外威胁方位、部件损毁和击毁反馈。投弹采用机头前向准心、损伤坡度限制和固定落点，武器按可攻击目标层判定命中。
- 参数化机身截面、翼面、短舱、炮塔与挂点；地形、云、飞机、弹道和准心 shader；所有主资源不依赖贴图文件。
- 三种画质、透明层/特效数量调节、简化阴影、DPR 上限和自动分辨率调节。
- 生命归零后的坠毁与结算，主动返航，重试与返回机库；最高分、最长存活、解锁、装备、金币和设置保存到 `localStorage`。
- 本地、最多 500 条的诊断事件缓冲，不上传网络；合成音效和可选触觉反馈。

## 代码入口

```text
src/app/GameApp.ts                 页面、会话和 DOM 界面
src/input/VirtualStick.ts          Pointer Events、触控捕获、死区和平滑
src/simulation/World.ts            固定步长、状态、导演和战斗规则
src/simulation/WindField.ts        确定性风场
src/simulation/FlightDynamics.ts   协调转弯、载荷包线与滚转惯量
src/simulation/types.ts            与渲染解耦的模拟数据
src/data/                         机体、武器、敌人、升级和手感参数
src/content/3d/AircraftFactory.ts  参数化飞机与部件装配
src/content/fx/CombatEffects.ts     战斗事件、特效批次与有界粒子池
src/content/2d/                    HUD、名牌、雷达、通用组件和图标
src/rendering/Renderer.ts          相机、场景、复用网格和动态分辨率
src/rendering/ShaderMaterials.ts   无贴图 shader
src/services/                     对象池、随机数、存档、音效、诊断事件
tests/simulation.test.ts           行为与耐久验证
tests/controls.test.ts             触控、键盘与屏幕中机头/飞行方向验证
tests/flight-dynamics.test.ts      倾角、动力、改装、回正与敌机转向惯性
```

模拟层以纯数据处理状态和事件。`World.frame()` 接收帧时间和输入，以 1/60 秒执行模拟，并限制追帧量。弹道使用相对于目标运动的扫掠检测。弹道与金币复用模拟池，特效和高频 HUD 元素分别复用渲染批次和 DOM 节点。
