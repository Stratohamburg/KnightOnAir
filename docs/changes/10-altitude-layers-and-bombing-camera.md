# 10 · 高度分层与轰炸镜头

> 状态：提案（**未实施**，只描述改动，不改源码/测试/基线文档）
> 基线：0.3.0（`5b22187`）；行号仅作快速索引，实施时以符号名为准。
> 触发需求（用户补充）：
> 1. **当前地面离飞机太近**，飞机应当飞得更高。
> 2. **轰炸时缩小 POV（视场角）**，才方便看清地面物体。
> 关系：本文定义**高度层与相机**的权威口径；[06 地面/地形](06-ground-routes-and-terrain.md) 的相对高度、[07 云](07-cloud-block-and-occlusion.md) 的云层高度、[09 投弹包线](09-bombing-envelope-and-aero-turn.md) 的投弹镜头都引用本文。
> 共享决策：00-overview 的 **D13（高度分层与镜头）**；D6 的“贴地飞行 +2”旧口径被本文的“高空巡航 +20”替代。

## 1. 问题与现状

### 1.1 飞机与地面几乎贴在一起

- 当前玩家视觉高度固定为 `y = 4`（`RENDERER` 中 `playerHeight = 4`，`src/data/config.ts:5`；`Renderer.ts:488-489` 的相机与 `ProceduralAircraft.ts:387` 的模型位置都按 4 处理）；06 规划改为 `terrainHeight + 5`。
- 地面在 `y = 0`（06 会变成真实起伏 0–10），也就是说飞机只比地面高 **5 个世界单位（约 10 m）**：从 62° 俯视时地面占满画面下方，飞机像“贴地滑行”；山脊/树/车辆离镜头太近，缺少“在空中”的尺度感。
- 空战敌人也在同一高度带（`Renderer.ts:597` 统一 `y = 4`），地面单位、弹道、爆炸、烟雾全部挤在相近高度，高度层没有信息量。
- 云层高度为 `terrain + 8/12/16`（07 的规划），与飞机 +5 的高度只差 3–11 单位：云几乎是“脚下的雾”，既挡不住敌机也没有“穿云”感。

### 1.2 轰炸时没有专门的观察镜头

- 相机全局只有一套：俯角 62°、距离 39、FOV 48°、yaw 固定（`src/data/config.ts:19`、`Renderer.ts:496-517`）。进入轰炸模式只改变准心和输入灵敏度，**相机完全不变**。
- 如果按 §1.1 把飞机抬高到 +20，地面目标在屏幕上的像素尺寸会明显变小；继续用当前 FOV，360×640 上车辆/设施会小到难以辨认，投弹手感下降。
- 需求“轰炸时缩小 POV”正好对应：轰炸模式切换到**窄视场（长焦）**的投弹镜头，把地面目标放大，同时保留机头前方的目标与准心。

### 1.3 高度层与其它系统的耦合

| 系统 | 当前/规划值 | 抬高后的影响 |
| --- | --- | --- |
| 玩家/敌机视觉高度 | `y=4` / `terrain+5` | 需要统一到 `terrain+20` 带 |
| 弹道/命中特效 y | 统一 4 | 需要跟随玩家/敌人高度带 |
| 炸弹下落 | `bombFallTime=0.85s`，从 y=4 落到 0 | 从 +20 落下需要更长时间与更明显的弧线，否则视觉上“瞬间落地” |
| 相机 | pitch 62°、dist 39、FOV 48° | 需要更大距离/更高俯角，否则地面被压缩 |
| 云层 | `terrain+8/12/16` | 需要抬到玩家高度带上下，才能既挡地面/敌机又不挡玩家（覆盖层） |
| 地形分块/雾 | 9×64 块、雾 40–115、far 180 | 高空视野更远，需要加大块尺寸/雾远端/far，避免边缘穿帮 |
| 锁定/轰炸准心/标签 | 世界 y 固定 | 必须用实际高度投影，否则 UI 与模型错位 |
| 08 大型机 | `visualSpan` 越大相机越远 | 高度抬高后，大型机的镜头距离需要重新标定 |
| 09 投弹包线 | 前向锥/坡度 | 目标在更高空中，准心/前向锥的投影与相机 FOV 强相关 |

## 2. 目标体验

- **真正在空中**：地面明显在脚下，能看见道路、车队、河流、云影的尺度；低空掠过的压迫感来自“靠近山脊”而不是“贴着地面”。
- **轰炸看得清**：进入轰炸模式，视野平滑收窄（长焦），地面车辆/设施放大、落点与准心清楚；退出后恢复广角巡航镜头。
- **高度有层次**：玩家、敌机、地面、云、弹道分布在不同高度带，HUD 与遮挡关系一致；飞机不再和地面挤在一层。
- **不增加操作负担**：仍是一根拇指；相机切换自动、平滑，玩家只需继续操作摇杆与投弹。

## 3. 目标设计

### 3.1 高度层定义（权威口径）

所有高度都相对**地形表面**（`surfaceHeight(x,z)`，06）表示；下表“世界单位”×2 为设计等效米。

```ts
// src/data/config.ts
export const ALTITUDE = {
  player: 20,        // 玩家巡航净空：terrain + 20（约 40 m）
  enemyBand: 4,      // 空中敌人在玩家高度带 ±4 内分配
  projectile: 20,    // 玩家/敌人弹道的视觉基准 y（跟随各自高度）
  bombStart: 20,     // 炸弹从玩家实际 y 开始
  groundClearance: 0.1,
} as const;

export const CAMERA = {
  // 巡航（替换 RULES.camera 的 pitch/distance/fov/far）
  distance: 46, pitch: 64, fov: 48, near: 0.1, far: 280, yaw: 0,
  // 轰炸镜头（09 §3.6 引用）
  bombing: { distance: 50, pitch: 74, fov: 34, transition: 0.35 },
} as const;
```

| 层 | 高度（相对地形） | 说明 |
| --- | ---: | --- |
| 地面/道路/单位 | `surfaceHeight + 0.05` | 06 的真实地形，最大山脊 18 |
| 地面火力/爆炸 | `surfaceHeight + 0.8 / 0.2` | 按现有特效 y 规则 + 地形 |
| 云层 L0/L1/L2 | **+14 / +28 / +42** | 见 §3.5；L0 在玩家下方，L1/L2 在玩家上方、相机下方 |
| 空中敌机 | `terrain + 20 ± 4` | 与玩家同一高度带，保持交火可读 |
| 玩家 | `terrain + 20` | 巡航净空 40 m 等效 |
| 相机 | 约 `player.y + sin(64°)×46 ≈ player.y + 41` | 俯视，地面可见范围显著变大 |
| 炸弹起点/弹道 | 玩家实际 y | 从高空落下，见 §3.4 |

> 与 06 的关系：06 原“贴地飞行 +5”改为本表；06 仍负责 `surfaceHeight/terrainHeight` 与地面单位贴地，10 只负责空中高度层。

### 3.2 高度迁移与所有依赖项

把“固定 y”改为“相对地形高度”后，所有系统统一按以下规则：

1. **玩家 y**：`p.y = damp(p.y, surfaceHeight(p.x,p.z) + ALTITUDE.player, 5, dt)`（阻尼 5/s，越山不跳变）；`prevY` 同步用于渲染插值。
2. **空中敌人 y**：生成时分配 `bandOffset ∈ [-4,+4]`，`e.y = damp(...surfaceHeight(e)+ALTITUDE.player+bandOffset...)`；轰炸机/精英可更靠上（+2）。
3. **弹道/导弹 y**：玩家子弹从 `p.y - 0.3` 射出，视觉上向目标高度插值；敌人 flak 从地面向 `p.y` 爬升；命中特效 y 取命中实体高度。
4. **炸弹**：`bomb.y` 从投弹瞬间 `p.y` 开始，按抛物线落到 `surfaceHeight(aim)+0.1`；`bombFallTime` **0.85s → 1.4s**（基线可调），渲染路径用同一时间参数，避免“几乎竖直瞬落”。落地爆炸/火焰/尘土仍贴地。
5. **阴影/贴花**：玩家/敌机阴影投到 `surfaceHeight+0.05`，阴影与机体距离变大（高空感）；低画质仍只画玩家与最近敌机。
6. **锁定环/目标环/准心/HUD**：全部用实体实际 y 投影；`Renderer.project(x,y,z)` 不再传固定 4/5/2，改传 `p.y`/`e.y`/`aim` 高度。
7. **烟雾/尾迹**：从部件世界高度发出，风场漂移在 XZ；高度下降/上升按部件 y。
8. **碰撞**：命中仍只做 XZ 线段扫掠（03/05 不变）；高度只影响表现，不新增三维命中。

### 3.3 相机（巡航）

- 参数：`distance 46`、`pitch 64°`、`FOV 48°`、`far 280`；`y = player.y + sin(64°)×46`，`z = player.z − cos(64°)×46`；lookTarget = `(p.x, p.y+2, p.z+1.5)`。
- 与现值的对比：距离 39→46、俯角 62→64、far 180→280；高度提升 +20 后，地面在画面中的占比从“贴脸”回落到可读的俯视战场，飞机轮廓仍足够大。
- 相机与地形：`cameraY ≥ surfaceHeight(cameraX,cameraZ) + 6` 防穿山；lookTarget 加轻微速度偏移（沿用现有阻尼），不改 yaw 固定、不改“上=前”的操作直觉。
- 大型机（08）：相机距离按 `visualSpan` 微调（现有 `displayDistance` 逻辑），但巡航距离基线统一 46；大型机最多再拉远 15%。

### 3.4 轰炸镜头（“缩小 POV”）

进入 `isBombing` 时，相机在 **0.35s** 内平滑过渡到投弹镜头：

| 参数 | 巡航 | 轰炸 | 说明 |
| --- | ---: | ---: | --- |
| FOV | 48° | **34°** | 视场角缩小约 29%，地面目标放大 ≈1.41×，即“缩小 POV” |
| pitch | 64° | **74°** | 更直视地面，减少远景压缩 |
| distance | 46 | **50** | 略微拉远，保证飞机与机头前方目标同时可见 |
| lookTarget | 玩家前方 1.5 | **lerp(玩家前方, aim, 0.55)** | 镜头重心向落点/准心偏移，地面目标居中 |
| 机位高度 | `p.y + 41` | `p.y + sin74°×50 ≈ p.y + 48` | 更高机位，俯视落点更清楚 |
| 过渡 | — | 0.35s ease | 退出/暂停/升级立即回到巡航参数 |

- **地面可读性目标**：360×640 下，轰炸模式中 2–3 单位宽的车辆占屏 ≥ 18px；准心、落点提示、锁定环不因 FOV 变化错位；`project()` 使用当前 FOV/pitch 计算，HUD 标签同步。
- **不遮挡操作**：轰炸镜头不改摇杆/按钮布局；相机过渡期间仍可操作（只改变视图），投弹按钮在校准完成后才可用（沿用稳定度）。
- **与 09 的联动**：09 的前向锥（±10°、4–14 单位）在轰炸镜头下投影；准心/锥边界随 FOV 同步；轰炸坡度限制不变。
- **例外**：进出轰炸的 0.35s 内不重置稳定度；暂停/升级/失焦冻结在当前插值位置，恢复后继续；从轰炸模式退出立即回巡航 FOV（不保留长焦）。
- **备选解释**：如果“缩小 POV”实际想要“看到更大范围”（广角），则把 FOV 调大而不是缩小；本文按“缩小视场角=放大目标”实现，见 §8-1。

### 3.5 云层跟随高度

07 的三层云高度从 `terrain + 8/12/16` 改为 **`terrain + 14/28/42`**：

- L0（+14）在玩家（+20）下方，负责遮挡地面与低空目标、形成“脚下云海”；
- L1（+28）、L2（+42）在玩家上方、相机（约 +61）下方，负责遮挡敌机/远景，玩家因覆盖层渲染仍可见；
- 云簇半径相应放大 1.2–1.5×（9–16 → 12–22），避免高空看云太小；画质档 4/7/10 簇不变；
- 云遮挡规则（D7：挡地面/敌机、不挡玩家）不变；玩家覆盖层只受 FOV/pitch 影响，不受云高度影响。

### 3.6 地形视野与分块

- 高空俯视需要更远的地形覆盖：06 的分块从 `64×64 / 20×20 / 9 块` 调整为 **`80×80 / 24×24 / 9 块`**，LOD 近景半径从 75 → **110**；雾从 `45–165` → **`70–240`**，`camera.far` 280。
- 远景山脊环半径从 110–360 → 160–520（省电档关闭）；森林/建筑物的实例数量按块面积等比增加，仍由 QUALITIES 控制。
- 地面单位/道路/水系/贴地逻辑不变（06 的职责）；高度层只改观察距离与分块参数。
- 验收：高空快速横飞 60s，无地形边缘穿帮、无 LOD 跳变、无雾墙；360×640 下地面目标仍能辨认（轰炸镜头下放大后）。

## 6. 验收标准

### 6.1 自动化

- **A1 高度**：玩家/敌机 `y ≈ surfaceHeight + 20`（误差 <0.7 稳态），不再出现固定 4；山区越脊时 y 随地形变化。
- **A2 投影**：`Renderer.project` 对玩家/敌人/HUD 使用实际 y 与当前 FOV；切换轰炸镜头后投影一致（误差 <1px 逻辑）。
- **A3 炸弹**：投弹起点 = 玩家 y；落点 = `surfaceHeight(aim)+0.1`；`bombFallTime=1.4s`；旧“落点不可变/冷却”断言保持。
- **A4 相机高度**：`camera.y ≥ surfaceHeight(cameraX,cameraZ)+6`；越山不穿地。
- **A5 轰炸镜头**：进入轰炸 0.35s 后 `fov≈34`、`pitch≈74`、`distance≈50`；退出后 0.35s 回到 48/64/46；同一目标在轰炸镜头下的屏幕尺寸约为巡航的 **1.35–1.45×**。
- **A6 过渡与例外**：暂停/升级/失焦期间镜头冻结；恢复后从当前值继续；不重置稳定度/冷却。
- **A7 云层**：三层高度为 `terrain+14/28/42`；L1/L2 在相机与敌机之间时敌机被遮挡、玩家始终可见（07 的覆盖层测试复用）。
- **A8 地形视野**：高空直飞 60s，地形块/雾/far 无边缘穿帮；draw call/三角形不超 D10 预算。
- **A9 现有测试**：`controls.test.ts` 的战斗相机复刻、`simulation.test.ts` 的投影/投弹/耐久断言按新相机与新高度更新后全绿；`project()` 签名不变。

### 6.2 真机/截图
