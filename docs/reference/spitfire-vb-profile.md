# Supermarine Spitfire Mk Vb

校验槽为 `falcon_13`。模型采用 B 翼、完整椭圆翼尖、舱盖闭合的 Mk Vb。外形资料与游戏槽位的武器、质量、升级参数分别记录。

侧、俯视取自 Marek Cel 的标准翼 Mk Vb 线图。文件名包含 3-view，图中只有两个投影。另取标有 **Spitfire VB** 的 Airwar 图页上方正视，主轮放下的虚线仅供识别位置。侧视图中省绘了桨叶、尾轮，保留此处图源可见性差异。[侧、俯视原图（CC0）](https://commons.wikimedia.org/wiki/File:Supermarine_Spitfire_Mk_Vb_3-view.svg) · [正视原图](http://www.airwar.ru/image/idop/fww2/spit5/spit5-3.gif) · [图页目录与型号](http://www.airwar.ru/enc/fww2/spit5.html)

## 读数与结构

两翼的描读数据在校验台“左右机翼原始读数与差值”内，可关闭原图查看拟合线，也可叠加原始描线。翼根整流遮蔽段停在可见外缘。配对容差为 2 单位，依据约 0.5–1 单位的笔划宽度、两侧取线与配准误差。俯视两侧轮廓在容差内。正视翼尖高度为 106 和 103，差 3，差值向翼根逐渐减小。正视保留两侧原始描线，模型按用户确认的双侧均值生成。该项单独记录，不能用它证明机翼实际装成不同高度。[双侧完整采样与模块标记](../../src/data/pistonFighterSheets.ts)

| 可见部件 | 所属结构及核对位置 | 状态 |
| --- | --- | --- |
| 机身、座舱、垂尾 | 侧视桨毂尖至尾端约 390 单位，风挡在桨毂后约 157 单位。前风挡、滑动罩、后窗沿机背排列 | 按侧俯外缘裁定各站宽高，后机身采用用户确认的椭圆 |
| 主翼、内襟翼、外副翼 | 主翼在翼根整流处与机身连接。副翼占外后缘，平尾与升降舵在尾段两侧 | 翼肋沿实测前后缘及双侧平均的上下缘放样 |

Mk V 系列的技术沿革也记录了左翼下更换较大直径滑油冷却器，并具体描述其圆形入口。BM597 的同型机照片可独立核对近侧左翼下的空速管、三叶桨与展开的主轮。[Mk Vb 冷却系统与改型记录](https://en.wikipedia.org/wiki/Supermarine_Spitfire_(early_Merlin-powered_variants)#Mk_Vb_(type_349)) · [BM597 实机照片](https://commons.wikimedia.org/wiki/File:Spitfire_F_VB_BM597.jpg)

用户已确认按原机保留右翼矩形冷却液散热器、左翼圆口滑油冷却器和左翼单根空速管。三者分别归属所在机翼。

## 截面复核

在桨毂后 250、300 单位处，俯视左右边界分别读作 (235.25,264.5)、(239.25,260.25)。同站位的侧视机背与机腹为 (74.2,125.8)、(78.8,119.2)。用户确认后机身沿这些椭圆截面过渡。UIUC 的翼型索引对 Supermarine 349 Spitfire VB 明列翼根 NACA 2213 和翼尖 NACA 2209.4。[翼型索引](https://m-selig.ae.illinois.edu/ads/aircraft.html)

## 实网格验收

以桨轴和机身中线配准，翼展 460 单位。外露主翼段的网格边缘到原图最近墨线的最大距离，正视为 1.5 单位，俯视为 1.0 单位。图纸省绘的桨叶与尾轮按飞行外观保留。冷却器正视开口分别按宽 29 和 11 单位建立，侧视以低多边形放样表达整流罩。 测量范围为距中线 30–230 单位，采样网格为每单位两像素。红线取自完整装配网格的正交投影。原稿中另示的收放位置和内部结构保留在黑色原图层。
