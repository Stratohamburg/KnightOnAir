# 格洛斯特流星 F.3 三视图记录

目标为 G.41D Meteor F.3 早期短舱外形。轮廓描点取自 500 × 374 像素的 G.41D 公开三视图预览。另一张标为 F Mk.III 的图用于核对双进气口和高置水平尾翼的布局。其俯面图斜置，当前保留为补充资料。 [G.41D 原图](https://www.the-blueprints.com/blueprints/ww2planes/ww2-gloster/5197/view/gloster_g41d_meteor_f3/) · [F Mk.III 补充图](https://www.the-blueprints.com/blueprints/modernplanes/modern-g/80248/view/gloster_meteor_f_mk_iii/)

前斜视照片显示短舱进气口、机翼和机身的接合。1945 年曼斯顿的 EE236 后斜视照片显示两个独立喷口以及水平尾翼与垂尾的结合。两张照片用来核对 F.3 的结构关系，照片中的发动机批次未用于确定 G.41D 站位。三视图中断开的轮子符号留在原图层，起落架收放构型与可见轮廓待确认。 [前斜视照片](https://commons.wikimedia.org/wiki/File:Gloster_Meteor_Mk_III_ExCC.jpg) · [EE236 后斜视照片](https://commons.wikimedia.org/wiki/File:Ground_crew_refuelling_a_Gloster_Meteor_F_Mk_III_of_No._616_Squadron_RAF_at_Manston,_Kent,_4_January_1945._CL2922.jpg)

叠合图按原图逐段描边，保留转折点和可见线的端点。JPEG 笔划通常约 1–3 像素宽。以至多 1 像素的步长沿各轮廓取样，记录每点到原图最近深色像素的距离。正视、侧视、俯视最大距离分别约为 2.1、2.0、2.3 像素，均在 2.5 像素的工作容差内。跨视图站位仍需用独立的证据核对。

## 左右对称校验

用原图的机身和座舱罩定位正视与俯视的中心线，分别采用侧移和转正后的横向零点。正视翼线参与面板转正和定标，正视翼尖结果一并作为配准检查。俯视的左右测点以机身基准为零分别读取。画面左右沿用图板标记。

本图用 5 图板单位作为双侧比较的工作容差。依据是原图 500 × 374 像素、通常 1–3 像素的线宽、每侧描线约 2.5 像素的工作容差，以及正视定标后接近 1 的换算比例。两侧的读数偏差可能叠加，取各自工作容差之和的近似值。下表坐标保留原图像素，差值由两侧分别配准后计算。正视的第二轴朝下，俯视的第二轴为距机鼻站位。

沿成对可见轮廓以最多 0.5 图板单位的步长双向比较镜像后到对侧线段的最近距离。正视进气唇口、开口、外翼和内翼上下缘的最大偏差分别为 3.7、1.9、3.1、3.2 单位。俯视短舱、外翼、内翼可见前缘及后缘、平尾分别为 3.5、2.5、2.0、1.1、3.2 单位。俯视短舱的最大差在后端附近（站位 169–173）。正视内翼靠机身处，画面左侧多出一段遮挡终止竖线，整体线链镜像时出现约 5.6 单位的差。比较两侧都可见的对应上下缘时差值为 3.2，遮挡下的接合面仍待证据。

已核对的对应测点及边界落在当前图纸容差内。经审核，归为图纸误差，按机身中心线 `x = 0` 镜像校正。H5 默认显示校正轮廓与定位点，可叠合参考图和校正前的描线。短舱前端的侧视与俯视站位仍按跨视图资料复核。

## 镜像校正

外翼沿用点位较密的图板左侧可见轮廓，翼尖拟合至两侧配准读数的中间值后镜像。正视内翼用两侧共同可见的上下边读数取中。正视进气唇口与开口沿用左侧描线，按两个开口中心的配准读数定位后镜像。俯视短舱沿用左侧描线，在纵向站位 77 和 173 处分别用双侧端面中点校准，沿站位内插横向修正量。

正视和俯视的机身、座舱罩与垂尾轮廓围绕中心线合拢或镜像已有可见段。尾翼沿用可见轮廓较完整的一侧，俯视平尾翼尖按双侧读数校准。图板上每个成对定位点具有相同的高度或纵向站位，横向坐标正负相反。侧视与俯视分别保留各自的短舱进气端读数。
