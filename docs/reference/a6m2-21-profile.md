## 读数与结构

校验台的读数表与图层保留正、俯视分别描出的双侧主翼边缘。以约 0.5–1 单位的笔划宽度、两边取点及配准误差确定 2 单位的配对容差。参与拟合的主翼蒙皮读数在容差内。原图左翼前方的空速管独立于蒙皮，只出现在俯视左侧。图上探管站位 x≈64，中心线 x=250，相距约 186，向前突出约 23 单位。[双侧完整采样与模块标记](../../src/data/pistonFighterSheets.ts)

## 截面复核

在桨毂后 210、240 单位处，俯视左右边界分别读作 (233,266.75)、(235.25,264.75)。同站位的侧视机背与机腹为 (73,114.8)、(75.2,112.8)，已排除机背天线。用户确认以图板椭圆作为机身截面。UIUC 翼型索引给 A6M 系列列出修形 MAC118，根、尖厚度比分别为 14.3% 和 9.4%。资料未列二一型折叠缝处的完整翼肋点列。[翼型索引](https://m-selig.ae.illinois.edu/ads/aircraft.html)

## 实网格验收

以桨轴和机身中线配准，翼展 460 单位。外露主翼段的网格边缘到原图最近墨线的最大距离，正视为 0.5 单位，俯视约 1.12 单位。展开折缝的两块网格共用同一条边界翼肋，左翼空速管随左翼节点显示。 测量范围为距中线 30–230 单位，采样网格为每单位两像素。红线取自完整装配网格的正交投影。原稿中另示的收放位置和内部结构保留在黑色原图层。
