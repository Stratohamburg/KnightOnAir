# 升级和构筑系统

## 设计目标

升级要同时改变数值、外观和操作手感。玩家看到的飞机轮廓就是当前构筑的直观结果。升级选择既可以让飞机更强，也可以把飞机推向更明显的流派。

每次达到经验阈值获得一次升级次数。玩家可以立即点击升级按钮，也可以保留次数，等待更安全的时间。触发后世界模拟暂停，控制区被三个纵向选项覆盖，玩家不能继续驾驶。

## 经验和升级次数

```text
requiredXp(level) = floor(80 + level * 45 + pow(level, 1.35) * 18)
```

经验来自空中金币、敌人击毁、地面轰炸和精英目标。达到阈值后。

1. 等级增加。
2. 可升级次数加一。
3. 升级按钮角标加一。
4. 经验条保留超出部分。

## 三选一流程

1. 玩家点击升级按钮。
2. `WorldClock.timeScale` 变为 0。
3. 摇杆和模式输入锁定。
4. 系统从合法候选池抽取三个不重复选项。
5. 选项纵向显示，靠近屏幕中央，优先适配右手拇指。
6. 每个选项显示升级前后变化和外观缩略图。
7. 点击选项后扣除一次升级次数。
8. 部件拼装和材质变化播放 0.35 到 0.6 秒。
9. 恢复世界时间，升级按钮刷新角标。

## 升级类型

### 结构部件

直接添加到机体挂点，改变尺寸、质量、碰撞和参数。

### 武器部件

增加武器挂点、炮塔或弹药舱，改变武器输出和攻击方式。

### 系统部件

改变能量、锁定、风场响应、修复和轰炸稳定度。

### 行为技能

通过运行时 buff 改变弹道、击毁奖励、连击或部件状态。

## 空间和流派规则

### 左右流派

左右增件会改变翼展、碰撞宽度、质量和左右转向率。

- 同侧发动机让动力更强，但对应方向转向稍迟钝
- 单侧武器让一侧输出更高，同时增加该侧迎弹面
- 对称增件更稳定，但通常牺牲一部分最大强度
- 极端左右不对称可以形成高风险高收益构筑

### 前后流派

前后增件会改变机身长度、惯性分布和武器射界。

- 机头增件强化前向火力和锁定
- 机尾增件提高速度保持、尾部防御和后向火力
- 前重机体转向响应变慢，但正面冲击更强
- 后重机体直线稳定性更高，但改变方向需要更大空间

### 大型化流派

增加大型机翼、装甲和外挂炮塔会形成巨无霸机体。

- 生命、挂点和火力增加
- 迎弹面和碰撞半径增加
- 加速度、转向率和风场抗性下降
- 部件被击中时损失更明确，适合维修和护航类升级

### 轻量化流派

拆除装甲、使用短翼和轻型发动机会保持小巧。

- 速度、转向、能量恢复和准心稳定提高
- 生命和单次火力偏低
- 小碰撞体降低被命中概率
- 适合依靠移动、锁定和精准轰炸取胜

## 升级冲突和合法池

升级选项必须考虑当前构型。

- 同一挂点的互斥部件不能同时出现
- 被摧毁的部件可以出现重装选项
- 需要机体结构的武器在缺少挂点时不出现
- 已经达到最高层级的部件不再进入候选池
- 候选池至少保留一个不依赖当前特殊构型的通用选项

## 反馈和可读性

每个选项卡显示四类信息。

- 外观缩略图，显示部件增加的位置和尺寸
- 主要增益，用绿色显示
- 主要代价，用橙色或红色显示
- 可能损坏的功能，用部件图标显示

升级选择界面要让玩家能快速回答以下问题。

- 飞机会变大还是变小
- 哪一侧会变长或变重
- 火力来自哪里
- 哪个参数会变差
- 部件损坏后会失去什么

## 部件损坏和升级关系

- 新增发动机单独拥有生命值和烟火状态
- 新增武器挂点可以被击毁，其他武器不受影响
- 结构部件损坏时保留外观轮廓，但变为黑烟、火焰或断裂状态
- 重新安装类升级可以恢复被摧毁的挂点
- 维修类升级增加部件生命或降低损坏后的性能惩罚

## 初版升级池

详细数据见 [初版升级部件](../content/INITIAL_UPGRADES.md)。初版先做以下路线。

| 路线 | 主要空间变化 | 主要收益 | 主要代价 |
| --- | --- | --- | --- |
| 右侧动力 | 右翼增加发动机 | 加速度、极速 | 右转迟钝、右翼变宽 |
| 左侧动力 | 左翼增加发动机 | 加速度、能量恢复 | 左转迟钝、左翼变宽 |
| 双侧动力 | 两翼各增加发动机 | 极速和持续加速 | 体积、能耗和迎弹面增加 |
| 机头火力 | 机头增加机炮或雷达 | 前向伤害、锁定速度 | 机身变长、转向响应变慢 |
| 机尾防御 | 机尾增加尾炮和装甲 | 后向防御、生命 | 机身变长、加速度下降 |
| 巨型翼 | 两翼加长并增加挂点 | 多武器和生命 | 转向、风场响应和迎弹面变差 |
| 轻型翼 | 翼展缩短、装甲减少 | 速度、转向、准心稳定 | 生命和挂点减少 |

## 验收标准

- 升级选项能改变飞机几何形状，而不是只更新数字。
- 左右增件会改变翼展、碰撞和左右转向差异。
- 前后增件会改变机身长度和惯性表现。
- 大型构筑拥有更高火力和生命，同时有更大的迎弹面和较差机动。
- 升级按钮数字、可用状态和选项面板状态准确。
- 部件损坏后对应的武器、动力或系统确实受到影响。
