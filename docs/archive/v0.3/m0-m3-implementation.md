## 早期实现选择

- 采用总设计中固定 `cameraYaw = 0` 的相机，摇杆向上始终对应屏幕向上。系统分文档里的随航向绕转示例与此不一致，因此没有采用绕机旋转。
- 空战主平面用 XZ；Y 仅参与空间表现、落弹与分层。模型本地 +Z 为机头。
- 固定相机看向 +Z，屏幕向右对应世界 −X。触控与键盘在输入输出时统一转换，修复左右反向；摇杆帽保持跟随手指，飞机保留转向惯性。
- 战斗相机距离最初从 32 调至 39，并直接读取 `RULES.camera.distance`（0.4 后进一步调整为巡航 66）。
- 参考本机 MadMax 的 `src/input/joystick.ts` 与圆环反馈设计：虚线半油门圈、实线满油门圈、金色满油门状态、加速进度环及百分比。
- 常规敌机模型放大至初始 Swift 相当或更大，碰撞半径随之调整；侦察/追猎/护卫的转向上限降为 80/90/85°/秒，转向采用渐进角速度，俯冲攻击机保留受加速响应约束的直线冲刺。
- `FlightDynamics.ts` 用协调转弯关系 `ω = −g·tan(bank)/v` 耦合倾角和航向，用推力储备、翼载与质量计算可用载荷，再以 `acos(1/n)` 得到倾角上限；滚转惯量随 `mass·span²` 增长，角速度受阻尼与速率限制。87.5° 是避免奇异值的数值保护。
- 四种初始机体在装备页均可预览；预览不写装备。Swift 和 Wasp 携带基础小型重力炸弹，Courier 和 Mastodon 的装填、稳定性与重型载荷形成差别。
- 商店与两个预留页保留设计要求的可返回占位内容。
- 省电/标准/高档位使用简化投影阴影，不启用昂贵的实时阴影贴图。三档分别从 0.70 / 0.85 / 1.00 分辨率比例起步，低帧率持续三秒时下调；下限 0.55，持续流畅后逐步恢复到所选档位。
- 所有战斗音效由 Web Audio 合成；浏览器尚未允许播放时可正常静音游玩。

## 自动化验证（0.3.0 基线）

`npm test` 在 M0–M3 基线运行了 39 项行为测试，覆盖：

- 真实触控事件与键盘的上下左右、触控四个斜向投影校验及取消复位。
- 半油门与满油门的行程/百分比/进度环一致，松手清零、轰炸油门限制、能量不足提示。
- 轻型/重型机侧倾包线、弱动力/损伤/巨型翼对操控包线的影响、协调转弯与回正连续性。
- 六类空中敌人的转向惯性、转速上限和有限状态。
- 30 / 60 / 120 渲染帧率下相同的固定步长结果；升级暂停、恢复无时间追赶、恢复先前轰炸模式。
- 锁定/失锁衰减与制导发射、高速投射物扫掠碰撞、轰炸稳定门槛与固定落点。
- 发动机减效、武器挂点失效、坠毁结算、经验溢出与三选一合法互斥池、存档恢复与降级。
- 四架初始机体各自 300 秒免伤自动驾驶耐久测试（活动实体 `< 250`）。

## 2026-11-19 浏览器初测记录

在本地 Vite 服务与内置浏览器完成以下验证：

- 360×640、390×844、430×932 和 1280×900：主界面、装备页、三选一面板及控制区无横向溢出；360×640 的三个升级选项均处于可见范围。
- 五个导航入口都能进入并返回。未解锁 Courier 的预览不会改变实际出击的 Swift。
- 实际拖动摇杆后，速度从 5.0 增至 7.3，能量降至 94%；释放后触控捕获、摇杆激活样式与摇杆帽偏移均清除。
- 开启轰炸后，稳定度达到 100% 才启用投弹；投弹产生装填倒计时，暂停和设置返回后保留轰炸模式与冷却。
- 升级暂停前后 HUD 时间都为 00:13；面板显示三个候选、收益/代价与数值比较；选中右侧发动机后新增部件，次数归零。
- 主动返航得到 717 分、27 金币，解锁 Courier；可以装备 Courier，刷新后仍保持该装备、最高分、金币与解锁状态。测试结束恢复 Swift 和标准画质。
- 检查期间浏览器没有记录控制台错误；内置浏览器约 8–12 FPS，仅用于功能与布局验证，不代表移动端性能。
- 同日操控调整后复查 360×640 与 430×932：满油门外圈、进度环、提示文字完整显示，实际向右拖杆后速度由 5.0 增至 9.1，松手回到巡航反馈且摇杆帽偏移清除。
