# 初版敌人设计

## 设计原则

每种敌人只承担一种主要教学职责。玩家通过轮廓、速度、颜色、音效和攻击预警，在透视相机下也能快速分辨目标。

敌人的生命、速度和伤害先以普通玩家机体为基准。导演系统根据玩家机体大小、输出和部件损坏调整数量与组合，不直接把所有数值无限提高。

## 空中敌人

### Scout-01 侦察机

#### 行为

- 从远处进入战场
- 在玩家侧前方绕行
- 不主动造成高伤害
- 在存活超过 8 秒后呼叫一组追猎机
- 被锁定或受伤后尝试向外撤离

#### 参数

| 参数 | 数值 |
| --- | ---: |
| 生命 | 40 |
| 速度 | 8.5 |
| 转向率 | 190°/秒 |
| 碰撞半径 | 0.55 |
| 接触伤害 | 8 |
| 经验 | 18 |
| 金币 | 2 |

#### 视觉

细长机身、短翼、顶部小型雷达球。使用亮黄色灯光和短促蜂鸣提示它正在呼叫增援。

### Hunter-02 追猎机

#### 行为

- 进入后追向玩家速度方向
- 在距离 11 到 17 的范围内尝试进入攻击角
- 用短点射机枪攻击
- 连续追击 4 秒后横向脱离，再重新进入

#### 参数

| 参数 | 数值 |
| --- | ---: |
| 生命 | 65 |
| 速度 | 9.5 |
| 转向率 | 220°/秒 |
| 碰撞半径 | 0.65 |
| 机枪伤害 | 5 |
| 射速 | 3 发/秒 |
| 经验 | 25 |
| 金币 | 3 |

#### 视觉

前掠翼和双尾喷口。攻击前炮管亮红，脱离时留下一条短尾焰。

### Bomber-03 轰炸机

#### 行为

- 以较低速度从侧前方横穿
- 在地面目标上方减速
- 投放地面预警圈和爆炸区域
- 投弹后继续直线飞行，适合被玩家从侧面拦截

#### 参数

| 参数 | 数值 |
| --- | ---: |
| 生命 | 130 |
| 速度 | 5.2 |
| 转向率 | 95°/秒 |
| 碰撞半径 | 1.1 |
| 炸弹伤害 | 55 |
| 炸弹冷却 | 6 秒 |
| 经验 | 55 |
| 金币 | 6 |

#### 视觉

宽机翼、腹部炸弹舱和两台发动机。发动机是可单独损坏部件，被击中后对应侧烟雾和速度下降。

### Escort-04 护卫无人机

#### 行为

- 围绕精英目标或轰炸机运动
- 与目标保持 6 到 9 单位半径
- 只在玩家接近保护圈时开火
- 精英目标被击毁后短暂失控，再向外逃离

#### 参数

| 参数 | 数值 |
| --- | ---: |
| 生命 | 45 |
| 速度 | 7.2 |
| 转向率 | 260°/秒 |
| 碰撞半径 | 0.45 |
| 激光伤害 | 4/秒 |
| 经验 | 28 |
| 金币 | 3 |

#### 视觉

三角形低面数机体，中心有保护环。保护状态使用蓝色连线显示。

### Striker-05 俯冲攻击机

#### 行为

- 从玩家侧上方进入
- 锁定玩家当前位置后进行一次高速俯冲
- 俯冲前显示方向箭头和短时预警
- 俯冲后需要大角度拉升，玩家可以在它转向时反击

#### 参数

| 参数 | 数值 |
| --- | ---: |
| 生命 | 80 |
| 巡航速度 | 7.0 |
| 俯冲速度 | 15.0 |
| 转向率 | 170°/秒 |
| 碰撞半径 | 0.6 |
| 接触伤害 | 28 |
| 经验 | 40 |
| 金币 | 4 |

#### 视觉

窄机翼和尖机头。俯冲时机身边缘出现白色速度线，拉升时喷出高亮尾焰。

### Elite-Airship-01 精英空艇

#### 行为

- 以低速占据战场中心附近
- 发射环形弹幕和追踪导弹
- 召唤护卫无人机
- 受损后随机关闭一侧武器
- 核心暴露时出现短暂高伤害窗口

#### 参数

| 参数 | 数值 |
| --- | ---: |
| 生命 | 650 |
| 速度 | 3.2 |
| 转向率 | 45°/秒 |
| 碰撞半径 | 2.8 |
| 环形弹伤害 | 12 |
| 导弹伤害 | 35 |
| 经验 | 220 |
| 金币 | 24 |

#### 可损坏部件

- 左侧炮台
- 右侧炮台
- 上方雷达
- 中央核心
- 左右推进器

#### 视觉

由低面数气囊、金属骨架和多个炮塔拼成。每个炮塔单独冒烟，核心暴露时内部发光。

- 固定在地面
- 先用红色瞄准线追踪玩家
- 0.8 秒后发射直线炮弹
- 炮管可以被轰炸单独摧毁

| 炮弹伤害 | 22 |
| 射程 | 30 |
| 射击间隔 | 3.2 秒 |
| 经验 | 35 |
| 金币 | 4 |

| 金币 | 6 |

### Resource-Truck-04 资源车

#### 行为

- 沿道路逃向地图边缘
- 不主动攻击
- 被击毁后掉落大量金币和经验
- 受到轰炸后短暂加速

#### 参数

| 参数 | 数值 |
| --- | ---: |
| 生命 | 100 |
| 车辆速度 | 3.8 |
| 经验 | 70 |
| 金币 | 18 |

#### 视觉

车顶使用发光资源箱，透视相机下容易识别。被锁定或轰炸时显示橙色目标环。

### Fuel-Depot-05 燃料设施

#### 行为

- 固定地面建筑
- 被炸毁后产生二次爆炸
- 爆炸会点燃附近的机枪阵地和车辆
- 是范围武器的高价值目标

| 金币 | 10 |

## 敌人部件损坏

首版至少给以下敌人实现局部部件。

| 敌人 | 部件 |
| --- | --- |
| 侦察机 | 雷达球、主发动机 |
| 追猎机 | 左右发动机、前机炮 |
| 轰炸机 | 左右发动机、炸弹舱 |
| 护卫无人机 | 中心核心、保护环 |
| 俯冲攻击机 | 机翼、发动机 |
| 精英空艇 | 左右炮台、雷达、推进器、核心 |
| 防空炮 | 炮管、炮座 |
| 导弹车 | 导弹舱、车体 |

部件受损会减少敌人的对应功能，并通过黑烟、火焰、断裂件和攻击频率变化表现。

## 生成和掉落规则

- 普通空中敌人从相机可见范围外进入
- 地面单位在远景地块生成，再随相机进入有效战区
- 关键目标不在玩家正后方突然生成
- 金币路线出现在玩家前方或侧前方，鼓励移动
- 精英事件前提前 2 秒显示云层变化和方向提示

## 验收标准

- 玩家可以从轮廓和攻击预警识别敌人职责。
- 空中、地面、精英和高价值目标拥有不同的处理优先级。
- 每种高威胁攻击都提供可理解的预警时间。
- 受损敌人会停止或削弱对应武器和部件功能。
- 资源车和燃料设施让轰炸模式拥有明确目标。
