# 初版升级部件设计

## 使用方式

升级部件通过经验等级获得。每次触发升级出现三个候选项，候选项来自当前机体的合法池。选择后立即安装到机体，播放拼装动画，并更新参数、碰撞体、武器和部件生命。

所有部件都包含可见几何体。几何体由简单棱柱、圆柱、盒体和连接支架组成。部件如果被击毁，会进入黑烟、火焰、失效或脱落状态。

## 部件标签

| 标签 | 作用 |
| --- | --- |
| `power` | 发动机、能量和加速 |
| `weapon` | 武器挂点、炮塔和弹药 |
| `structure` | 机翼、机身、装甲和生命 |
| `control` | 转向、稳定和风场响应 |
| `bombing` | 炸弹舱、准心和范围伤害 |
| `lock` | 雷达、扇形和锁定时间 |
| `repair` | 部件生命、维修和损坏惩罚 |

## 普通升级

### Right-Engine-01 右侧辅助发动机

#### 位置和外观

- 安装在右翼前缘外侧
- 翼展增加 1.2 单位
- 使用圆柱发动机、喷口环和两根连接支架
- 右侧尾焰在加速时更亮

#### 参数变化

| 参数 | 变化 |
| --- | ---: |
| 加速度 | +16% |
| 极速 | +0.8 |
| 能量消耗 | +8% |
| 右转率 | -8% |
| 左转率 | +4% |
| 右翼部件生命 | 28 |

#### 损坏

## 升级组合示例

### 右侧火力翼

`Right-Engine-01` + `Wing-Gun-01` + `Wing-Turret-02`

- 右侧拥有更多动力和火力
- 右转更迟钝，左转更灵活
- 右翼变长并形成明显迎弹面
- 适合绕着目标逆时针转向

### 巨无霸轰炸机

`Giant-Wing-01` + `Heavy-Armor-02` + `Bomb-Bay-01` + `High-Pressure-Engine-02`

- 机体大、生命高、范围伤害强
- 需要提前转向并管理能量
- 发动机和翼部成为优先保护区域

### 轻巧锁定机

`Low-Drag-Wing-01` + `Nose-Radar-01` + `High-Pressure-Engine-02`

- 速度、转向和锁定速度高
- 生命低，发动机损坏影响大
- 通过提前量和持续移动规避攻击

## 候选池约束

- 第一次升级保证出现一个基础控制或动力选项。
- 大型部件不会连续三次出现，避免机体突然失去可操作性。
- 左右部件在同一局内尽量形成可读的对称或明确非对称路线。
- 已经安装单侧发动机时，提高另一侧发动机的出现权重。
- 巨型翼和重型装甲出现后，提高发动机、轰炸和维修类选项权重。
- 机体核心生命低于 45% 时，增加维修和部件修复选项。

## 验收标准

- 每个初版升级都有可见几何体和部件挂点。
- 左右、前后和大型化升级能产生不同的机体轮廓。
- 升级带来的数值收益和操控代价在选项卡中可读。
- 发动机、武器、机翼和炸弹舱升级都能独立损坏。
- 初版升级池能稳定生成轻型、重型、左右非对称和轰炸四类流派。
