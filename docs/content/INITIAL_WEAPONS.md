# 初版武器设计

## 数值说明

- 伤害是对普通敌人机身的基础单次伤害。
- 射速使用每秒发射次数。
- 射程使用世界单位。
- 锁定时间是目标保持在有效扇形内需要的秒数。
- 炮塔转速使用角度每秒。
- 爆炸范围是世界单位半径。

## 轻型机炮 `light_cannon`

### 定位

Wasp-04 的默认武器。射速高、散布小、单发伤害低，要求玩家保持目标在前方扇形内。

### 参数

| 参数 | 数值 |
| --- | ---: |
| 分类 | 定向 |
| 单发伤害 | 6 |
| 射速 | 8 发/秒 |
| 弹速 | 24 |
| 射程 | 24 |
| 扇形宽度 | 20° |
| 齐射 | 1 |
| 散射 | 0° |
| 穿透 | 0 |
| 爆炸范围 | 0 |

### 表现和命中

- 弹体是细长发光棱柱
- 命中显示小火花和白色伤害数字
- 连续命中同一部件时增加轻微热量
- 适合击毁追猎机和侦察机

## 双联机炮 `nose_cannon_pair`

### 定位

Swift-01 默认武器。两条前向炮管从机头左右发射，单次齐射伤害高，适合抓住转向窗口。

### 参数

| 参数 | 数值 |
| --- | ---: |
| 分类 | 定向 |
| 单发伤害 | 11 |
| 射速 | 4 发/秒 |
| 弹速 | 28 |
| 射程 | 28 |
| 扇形宽度 | 22° |
| 齐射 | 2 |
| 散射 | 1.5° |
| 穿透 | 0 |
| 爆炸范围 | 0 |

### 额外规则

- 机头受损后两门炮可以分别卡顿
- 两门炮共享射速冷却，但各自使用实际挂点
- 机炮升级可以增加穿透或缩小散射

## 双翼机枪 `wing_machinegun_pair`

### 定位

Courier-02 默认武器。两侧翼根各一挺，火线稍宽，玩家可以通过航向变化制造提前量。

### 参数

| 参数 | 数值 |
| --- | ---: |
| 分类 | 定向 |
| 单发伤害 | 8 |
| 射速 | 5 发/秒 |
| 弹速 | 22 |
| 射程 | 22 |
| 扇形宽度 | 26° |
| 齐射 | 2 |
| 散射 | 2.5° |
| 穿透 | 0 |
| 爆炸范围 | 0 |

### 额外规则

- 单侧机枪被击毁后，另一侧继续射击
- 右侧升级机枪会增加右侧翼展和右侧迎弹面
- 两挺机枪都存活时，连续命中会提高连击倍率

## 四联重机枪 `heavy_machinegun_quad`

### 定位

Mastodon-03 默认正面火力。四门炮从左右翼和机头同时输出，适合大型目标和护卫编队。

### 参数

| 参数 | 数值 |
| --- | ---: |
| 分类 | 定向 |
| 单发伤害 | 9 |
| 射速 | 7 发/秒 |
| 弹速 | 25 |
| 射程 | 27 |
| 扇形宽度 | 28° |
| 齐射 | 4 |
| 散射 | 3.5° |
| 穿透 | 1 |
| 爆炸范围 | 0 |

### 额外规则

- 每个炮管有独立的损坏挂点
- 至少两个炮管存活时保持齐射
- 只剩一个炮管时退化为单发连续射击

## 机背自动炮塔 `top_turret`

### 定位

覆盖侧后方的独立炮台。它不要求飞机正对目标，但旋转速度有限。

### 参数

| 参数 | 数值 |
| --- | ---: |
| 分类 | 炮台 |
| 单发伤害 | 7 |
| 射速 | 4.5 发/秒 |
| 弹速 | 21 |
| 射程 | 21 |
| 炮塔转速 | 110°/秒 |
| 炮塔角度 | 270° |
| 扇形宽度 | 14° |
| 穿透 | 0 |

### 额外规则

- 机背炮塔受损后转速降低
- 炮塔被击毁后，挂点留下冒烟底座
- 炮塔优先选择玩家侧后方的追猎机

## 翼端旋转炮塔 `wing_turret`

### 定位

安装在左翼或右翼尖端的非对称武器。它扩大翼展，制造更强的侧向火力，也让相应方向更容易被击中。

### 参数

| 参数 | 数值 |
| --- | ---: |
| 分类 | 炮台 |
| 单发伤害 | 10 |
| 射速 | 3.2 发/秒 |
| 弹速 | 23 |
| 射程 | 24 |
| 炮塔转速 | 80°/秒 |
| 炮塔角度 | 180° |
| 扇形宽度 | 16° |
| 穿透 | 1 |

### 额外规则

- 左右炮塔可以选择不同目标
- 对应翼端损坏时炮塔立即失效
- 对称安装后形成双侧火力，但明显增加迎弹面

## 火箭巢 `rocket_pod`

### 定位

挂在机翼下方或机腹的齐射武器。火箭速度比机炮慢，但命中后产生小范围爆炸。

### 参数

| 参数 | 数值 |
| --- | ---: |
| 分类 | 定向 |
| 单发伤害 | 24 |
| 射速 | 0.8 齐射/秒 |
| 弹速 | 15 |
| 射程 | 30 |
| 扇形宽度 | 18° |
| 齐射 | 4 |
| 散射 | 5° |
| 穿透 | 0 |
| 爆炸范围 | 2.2 |
| 制导 | 否 |

### 额外规则

- 齐射后进入较长冷却
- 命中地面目标时可以摧毁小型炮台
- 火箭巢损坏后齐射数量减少

## 锁定导弹 `lock_missile`

### 定位

处理精英敌人、轰炸机和高血量目标。需要玩家用飞机朝向保持目标在锁定扇形内。

### 参数

| 参数 | 数值 |
| --- | ---: |
| 分类 | 定向 |
| 单发伤害 | 75 |
| 射速 | 0.5 发/秒 |
| 弹速 | 12 |
| 射程 | 40 |
| 锁定扇形 | 18° |
| 锁定时间 | 1.2 秒 |
| 失锁衰减 | 50%/秒 |
| 爆炸范围 | 2.8 |
| 制导转速 | 150°/秒 |
| 制导存活 | 4 秒 |
| 需要伴随 | 否 |

### 锁定反馈

- 进入扇形时显示蓝色宽扇形
- 进度 50% 时变为黄色并开始收窄
- 进度 85% 时变为红色并播放加速音
- 完成时变为白色短脉冲并发射
- 目标离开时保留少量进度，玩家可以快速重新捕获

## 重力炸弹 `gravity_bomb`

### 定位

Courier-02 默认轰炸武器。单点高爆，冷却短，适合地面炮台和资源车。

### 参数

| 参数 | 数值 |
| --- | ---: |
| 分类 | 范围 |
| 对地伤害 | 120 |
| 爆炸范围 | 4.5 |
| 冷却 | 4 秒 |
| 投弹高度修正 | 0 |
| 持续时间 | 0 |

### 额外规则

- 只有绿色稳定准心时可以投弹
- 投弹时显示抛物线和落点阴影
- 炸弹舱损坏后冷却增加或暂时失效

## 重型炸弹 `heavy_bomb`

### 定位

Mastodon-03 默认范围武器。爆炸范围大，适合同时清理多个地面目标。

### 参数

| 参数 | 数值 |
| --- | ---: |
| 分类 | 范围 |
| 对地伤害 | 220 |
| 爆炸范围 | 7.5 |
| 冷却 | 7 秒 |
| 击退 | 1.5 |
| 持续时间 | 0 |

### 额外规则

- 投弹后轰炸模式保持开启
- 爆炸边缘伤害衰减到 30%
- 大型炸弹会产生更明显的地面裂纹和尘柱

## 凝固汽油弹 `napalm_bomb`

### 定位

持续区域武器，适合封锁地面炮台和道路。

### 参数

| 参数 | 数值 |
| --- | ---: |
| 分类 | 范围 |
| 初始伤害 | 45 |
| 每秒伤害 | 28 |
| 爆炸范围 | 3.5 |
| 冷却 | 8 秒 |
| 持续时间 | 5 秒 |
| 点燃 | 是 |

### 额外规则

- 地面生成橙红色持续区域
- 云层和风会让火焰偏向一侧
- 火焰区域对进入其中的敌人持续造成伤害
