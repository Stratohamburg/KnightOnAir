# 初版局外 UI 内容

## 初版页面清单

| 页面 ID | 页面名称 | 可用状态 | 默认入口 |
| --- | --- | --- | --- |
| `sortie` | 出击 | 可用 | 是 |
| `equipment` | 装备 | 可用 | 否 |
| `shop` | 商店 | 预留占位 | 否 |
| `reserved_a` | 预留一 | 预留占位 | 否 |
| `reserved_b` | 预留二 | 预留占位 | 否 |

## 底部切换栏内容

### 商店

- 图标建议使用简化货箱或金币袋
- 文案为“商店”
- 第一版点击后进入“即将开放”占位页
- 入口保留红点数据结构，但第一版不显示红点

### 装备

- 图标建议使用飞机轮廓或扳手
- 文案为“装备”
- 点击后进入飞机选择和部件预览
- 当前装备飞机的机体图标可以显示在入口右上角

### 出击

- 图标建议使用向上箭头、起飞跑道或机头轮廓
- 文案为“出击”
- 默认选中
- 选中时使用最亮颜色和轻微呼吸动画

### 预留一

- 第一版文案为“预留”
- 使用半透明占位图标
- 点击后显示“内容准备中”

### 预留二

- 第一版文案为“预留”
- 使用半透明占位图标
- 点击后显示“内容准备中”

## 出击页初版内容

### 顶部

- 玩家等级
- 局外金币
- 设置图标预留

### 3D 展示区

- 显示当前装备机体
- 飞机朝屏幕上方持续飞行
- 尾焰、云层和地面保持低速循环
- 机体部件使用当前装备构型
- 机体受损局外状态显示为完整构型
- 机体切换时显示短暂的高亮和尾焰增强

### 信息区

默认显示以下内容。

- 机体名称
- 机体定位，例如“轻型截击”“平衡攻击”“重型武装”
- 极速
- 加速度
- 转向率
- 生命
- 能量
- 当前武器图标
- 构筑标签，例如“轻量”“右侧火力”“轰炸”“巨型机体”

### 出击按钮

| 状态 | 文案 | 视觉 |
| --- | --- | --- |
| 默认 | 出击 | 高亮按钮，持续轻微呼吸 |
| 点击后 | 准备起飞 | 按钮锁定，显示进度环 |
| 加载中 | 进入第一关 | 低频闪烁，禁止重复点击 |
| 加载失败 | 重试出击 | 恢复可点击状态 |

第一版只需要一个副本入口，因此不显示关卡选择列表。出击按钮旁边可以显示“第一关”小标签，让玩家明确目标。

## 装备页初版内容

### 机体列表

初版显示四架机体。

| 机体 | 状态 | 卡片副标题 |
| --- | --- | --- |
| Swift-01 | 默认解锁 | 轻型截击 |
| Courier-02 | 可解锁 | 平衡攻击 |
| Mastodon-03 | 可解锁 | 重型武装 |
| Wasp-04 | 可解锁 | 轻量侦击 |

未解锁机体显示轮廓预览、解锁条件和“查看”按钮。已解锁机体显示“装备”按钮。

### 预览区

- 预览机体缓慢向前飞行
- 允许拖动或点击左右箭头查看不同机体
- 预览场景只改变相机轨迹，不改变战斗控制逻辑
- 机体的左右翼、前后挂点和炮塔使用当前数据生成

### 参数区

参数显示顺序固定。

1. 生命
2. 极速
3. 加速度
4. 转向率
5. 能量
6. 翼展和迎弹面

参数条使用低、中、高三个区间，同时显示实际数值。迎弹面不显示为单纯的“越高越好”，使用“机体体积”或“受弹面积”说明它的代价。

### 部件区

部件按空间位置分组。

- 机头
- 左翼
- 右翼
- 机身
- 机背
- 机腹
- 机尾

点击分组时，3D 预览高亮对应区域，信息卡显示部件名称、主要作用和当前武器。

## 占位页初版内容

商店、预留一和预留二共用占位页模板。

```text
┌─────────────────────────┐
│ 页面名称                 │
│                         │
│        内容准备中        │
│                         │
│   这里会开放更多功能      │
│                         │
│        [返回出击]        │
├─────────────────────────┤
│ 商店 │ 装备 │ 出击 │ 预留 │ 预留 │
└─────────────────────────┘
```

占位页的页面名称来自底部导航配置，避免未来替换页面时修改导航框架。

## 第一关入口

第一关使用以下入口文案和过渡反馈。

- 主按钮文案“出击”
- 小标签文案“第一关”
- 点击后飞机尾焰增强
- 云层速度加快
- 相机前视距离增加
- 画面短暂向前推近
- 0.6 到 1.0 秒后进入第一关加载状态

进入战斗后将当前局外装备复制为战斗初始构型，局内升级和部件损坏从这一份副本开始计算。

## 文案和状态原则

- 按钮文案使用短动词，例如“装备”“出击”“返回”
- 锁定状态用明显的按钮反馈，不使用无意义的长提示
- 占位内容明确显示“内容准备中”，不伪装成可用系统
- 飞机选择和出击状态始终显示当前装备机体名称
- 页面切换不能让玩家误以为已经更换了实际装备
