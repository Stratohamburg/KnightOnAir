# 时代内容与配置规范

本文档定义四时代的内容分期范围、配置读取与校验规则、默认装配基线与 `localStorage` 存档 v2 约定。0.4 评审取舍详见 [0.4 方案评审](archive/v0.4/design-review.md)，各时代详细候选配置表见 [0.4 时代提案 13–16](archive/v0.4/proposals/13-era-pioneer-config.md)。

## 四时代的可玩范围

关卡时代依次为萌芽期、一战、二战、初代喷气。机库、展厅和战斗收录原型校验台已有可用 3D 模型的 14 架机型。每关按关卡时代选择敌人和升级。提案 13–16 中的机型表属于历史规划。

| 时代 | 可装备机型 |
| --- | --- |
| 萌芽期 | Wright Flyer、14-bis、Demoiselle、Blériot XI、Etrich Taube、Deperdussin Monocoque、Caudron G.3、Ilya Muromets、Voisin III、Farman MF.11 |
| 一战 | 福克 Dr.I |
| 二战 | 喷火 Mk Vb、零式 A6M2 二一型、Ho 229 V2 |
| 初代喷气 | 初代喷气关使用当前装备机体。流星 F.3 和 Vampire 留在校验台继续补充资料。 |

萌芽期的 10 架飞机沿用校验台现有网格，近似和待核对项见各自校验页。它们默认解锁，并在游戏中配置一挺机枪。二战机型随单局最高分解锁。[机体数据](../src/data/aircrafts.ts)

## 配置读取与校验规则

- **机体与部件绑定**：机体 ID 跨版本稳定。数据声明基础部件、挂点、默认装配、时代、构型和重装容量。局内把安装位置绑定到实际部件，部件失效后按该绑定关闭武器。结构件叠层时同步更新外形、命中区、附加质量与可用挂点。[机体配置提案](archive/v0.4/proposals/11-airframe-config-and-refit.md)
- **按时代解析变体**：同一基础敌人 ID（如 `hunter`）在不同时代可拥有不同生命和装配。以“基础 ID + 关卡时代”解析唯一变体，保留基础 ID 用于行为和统计；显式覆盖值直接作为最终值，无覆盖值字段由基础值乘一次时代系数。比如萌芽期 `hunter` 的生命值是显式的 `39`，载入后仍必须是 `39`，不能再次乘时代系数。
- **严禁静默回退**：每个已启用的装配、编队、召唤和升级引用必须解析到具体 ID，按挂点类型、尺寸、数量和允许目标层校验；平台炮塔射界与单发散布分别配置；水面单位占用地面/水面共享预算。[敌人与武器提案](archive/v0.4/proposals/12-enemy-weapon-config.md)
- **武器进入抽选池的条件**：新弹种和行为必须同时在模拟、反馈和目标层可用，并通过配置校验后才能加入升级或敌人抽选池。对没有弹舱或默认炸弹的机型，出击、HUD 和升级预览均须正确处理空装配，投弹入口清晰显示不可用，不得假设每架机体都有合法炸弹返回值。[战斗实现](../src/simulation/World.ts)

## 新玩家起点与存档 v2 约定

- 新玩家默认装备福克 Dr.I（`heron_09`）。首关「黎明草甸」使用福克 Dr.I，自由巡航使用当前装备机体。旧存档装备下架机型时回到福克 Dr.I，原有分数、资源和仍在名录中的机体解锁记录可继续使用。
- **存档存储键**：现行实现使用 `knight-on-air.v2`，只接受版本号 `2`。旧 `knight-on-air.v1` 及其他版本或损坏 JSON 读取后直接初始化默认数据，不做旧档权益迁移；写入失败时在内存中保留当前状态继续游玩。[现行存档实现](../src/services/Save.ts)
- **验收要点**：覆盖新档、旧 v1 重置、损坏 JSON 与写入失败降级；各时代用固定种子验证开场、波次、增援、升级、投弹入口与结算解锁。
