# 0.4 地形与云实施方案

## 目标

本阶段把地面和云从表现层贴片升级为确定性、可遮挡、适合移动端的 Q 版 lowpoly 世界。视觉方向采用大色块、低模几何、平面法线、三段式卡通明暗、暖色受光和偏冷阴影。所有地形高度由模拟层和渲染层共同读取，云簇参与深度遮挡，但玩家、玩家弹道和关键瞄准信息保持清晰。

## 当前基线

- `src/simulation/Terrain.ts` 已有基础高度采样、地表高度和高度层辅助函数。
- `src/simulation/Routes.ts` 已有确定性路线点和路线方向的最小接口。
- `src/rendering/Renderer.ts` 仍使用 9 块水平平面，地形高度只由 shader 做视觉位移。
- `src/rendering/ShaderMaterials.ts` 的云仍是透明平面，关闭深度写入，不能遮挡地面或敌机。
- Renderer 目前只有一次主场景渲染，没有玩家覆盖层。

## 地形方案

### 高度场

高度只由 `seed + worldX + worldZ` 决定，禁止依赖玩家状态、画质档位或随机调用。最终高度按以下顺序生成。

```text
域扭曲
→ 低频主体起伏
→ 高频细节
→ 山脊抬升
→ 河道下切和水面限制
→ 道路、铁路、桥面压平
```

基线范围为常规陆地 0–10、远景山脊最高 18、河床最低约 -3.5、水面 -1.5。`surfaceHeight()` 返回最终可贴地高度，`terrainNormal()`、`isWater()` 和路线遮罩由同一套采样逻辑导出。

### 地形块

新增 `src/rendering/TerrainChunks.ts`，维护玩家周围 3×3 共 9 块地形。

| 区域 | 规格 |
| --- | --- |
| 近景块 | 80×80，24×24 段，使用真实高度顶点 |
| 远景块 | 80×80，10×10 段，降低采样密度 |
| 远景环 | 低模山脊轮廓，标准档和高档开启 |
| 低档 | 全部使用远景细节级别 |

每个顶点写入 `position`、`normal`、`height`、`surfaceMask`、`roadMask` 和 `shoreMask`。shader 只负责颜色、轻微颗粒、光照和雾，不再修改高度。

### 地面风格

地面采用大面积色块和少量实例化物件。草地、沙地、岩石、道路和水面各自使用 2–3 个相邻颜色，通过法线和太阳方向形成三段式明暗。道路使用宽色带，铁路使用实例化轨枕和钢轨，岸线使用浅色泡沫。树、岩石、路牌和建筑按固定种子摆放，避开水面、道路和陡坡。

推荐色板如下。

| 表面 | 颜色 |
| --- | --- |
| 草地 | `#A6E36D` |
| 沙地 | `#F0D48A` |
| 水面 | `#5FD3E8` |
| 道路 | `#EAD6A6` |
| 山体 | `#8AE0B0` |
| 天空 | `#A9DFFF` |

## 云方案

### 云簇结构

新增 `src/rendering/CloudField.ts` 负责纯数据生成。每个云簇由 6–9 个共享几何团块组成。

- 主团使用 `IcosahedronGeometry`。
- 辅助团使用 `BoxGeometry`，提供卡通棱角。
- 主团、2–3 个中团和 3–5 个小团组合成一个簇。
- 团块使用不同缩放、旋转和少量明度种子。
- 云簇整体移动，团块不逐帧旋转。
- 云簇半径 12–22，底部略平，形成积云平底。

### 云层

| 层 | 高度 | 作用 | 漂移速度 |
| --- | --- | --- | --- |
| L0 | `terrain + 14` | 遮挡地面和低空敌机 | 0.8 |
| L1 | `terrain + 28` | 中景填充和敌机遮挡 | 1.1 |
| L2 | `terrain + 42` | 远景剪影和云影 | 1.4 |

画质档位使用 4 / 7 / 10 个云簇。云簇通过相机距离、玩家距离和环绕边界淡出，避免贴脸和坐标环绕跳变。

### 云材质

云主体使用不透明、写深度的材质。颜色采用三段式卡通明暗。

- 顶部受光使用奶油白 `#FFF6E5`。
- 中间调使用 `#F3EBDD`。
- 云底使用偏蓝阴影 `#B7D2EA` 和 `#9DBEDC`。
- 云底加入低强度暖橙反弹光 `#FFC39A`。
- 边缘使用低强度 fresnel 高光。

每簇可以有一张低透明度实例化软影，贴在 `surfaceHeight()` 上，强化云和地面的空间关系。

## 遮挡方案

Renderer 改为两个场景共享同一相机。

```text
主场景
  地形、地面单位、敌机、敌方弹道、爆炸、云簇
清除深度
覆盖层
  玩家飞机、玩家弹道、锁定环、准心、投弹轨迹
DOM
  雷达、边缘提示、HUD、击毁信息
```

主场景中的云使用深度写入，遮挡地面、敌机和敌方弹道。玩家覆盖层在 `clearDepth()` 后绘制，保证玩家和关键瞄准信息不被云压住。敌机名牌根据云遮挡结果淡出，雷达和边缘提示继续显示。

## 实施顺序

1. 完成确定性高度场、道路遮罩、河道、水面和法线接口。
2. 新增真实高度地形块，替换 Renderer 的 9 块平面。
3. 让地面单位、树、岩石、建筑、阴影、爆炸和炸弹落点读取同一地表高度。
4. 新增云簇数据和共享低模几何，先完成主场景中的不透明云。
5. 新增玩家覆盖层和双 pass 渲染。
6. 加入云影、名牌淡出、远景山脊和水面细节。
7. 统一颜色、光照、雾和 Q 版轮廓。
8. 在 360×640、满额敌人和云层场景下测量绘制次数、三角形和帧时间。

## 第一批交付

第一批先完成可验证切片。

- 确定性草地高度场。
- 9 块真实地形网格。
- 一条道路和一条河的基础遮罩。
- 4–7 个云簇。
- 每簇 6 个以上低模团块。
- 不透明云主体。
- 玩家覆盖层渲染入口。
- 基础水面和岸线颜色。

## 验收条件

- 相同种子和坐标得到一致高度。
- 地形块移动时没有明显接缝或闪烁。
- 地面单位、树、阴影和爆炸贴合地面。
- 云团拥有顶面、侧面和蓝色云底，画面中不再出现矩形云片。
- 云可以遮挡地面和敌机。
- 玩家飞机、玩家弹道、锁定环和投弹准心始终可见。
- 标准档云三角形低于 25k，整帧绘制次数低于 150。
- `npm run build` 通过，已有模拟测试不出现新的失败。

## 当前实现进度

第二批已经完成以下内容。

- 云主体改为不透明低模卡通材质，加入顶部受光、中间调、蓝色云底和边缘暖光。
- 云簇增加地面软影，使用实例化网格并随画质档位控制数量。
- 地形块增加跟随环心的水面平面和轻量水面 shader。
- 地面和水面敌人接入路线字段、路线采样和车队推进。生成时会先把单位放到路线，再用实际位置检查屏外条件。
- 轰炸镜头接入 0.35 秒级别的阻尼过渡，巡航到轰炸时调整 FOV、距离、俯角和注视点。
- 玩家弹道和炸弹迁移到覆盖层，炸弹路径、落点、准心、目标环、火焰和阴影读取实际地表高度。
- 配置 v3 的玩家机体、敌人载体和 NPC profile 注册表已恢复，四架现有机体和现有敌人均可通过配置解析。
- 铁路路线增加轨枕、钢轨和跨水桥面，公路路线增加路侧标志和路边设施，地形环增加远景低模山体。
- 敌机名牌投影使用当前云簇和相机到目标的线段遮挡测试，被云挡住时平滑降低不透明度，雷达和边缘提示继续保留。

0.4.0 接入了四时代的关卡色彩与地表配置。公路、铁路和水路使用实际里程采样，地面与水面单位沿路线移动并按车距限制前进。机库与战斗使用程序化机翼层数、推进器、飞艇囊体、浮筒和飞行艇船身。云与弹道使用实例化绘制，敌机静态部件按材质合并绘制。

2026-11-20 在 Chrome 的 360×640 视口验证四时代出击。标准档实际渲染分辨率为 306×544，满额 14 个敌人与 140 枚弹道的场景中，巡航为 125 次绘制、40,088 个三角形，进入轰炸后为 92 次绘制、39,050 个三角形。同一地面物体的屏幕宽度增至约 1.36 倍。移动设备上的持续帧率、触屏误触和长期平衡需要实体设备记录。
