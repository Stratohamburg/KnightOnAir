# 渲染与视觉指南

本文档定义《Knight on Air》现行的视觉原则、移动端性能红线，以及确定性地形、连续体积云、风动植被与双 Pass 遮挡的渲染方案。早期 0.4 低模云簇方案与第一/二批历史施工记录已归档至 [0.4 早期地形与云方案](archive/v0.4/terrain-cloud-plan.md)；最新实测数据与复现命令见 [验收基准与测试指南](VERIFICATION.md)。

## 俯视角视觉原则（光遇·云野基线）

本游戏是**移动端竖屏（360×640）固定俯视角**空战游戏，第一版视觉标杆明确对标**《光·遇》云野（Daylight Prairie）**的晴天多云明媚氛围。后续任何渲染迭代必须遵守以下硬规则，避免套用第三人称平视大世界方案导致视觉发灰或性能失控：

1. **视野内 100 分，视野外 0 分**：默认巡航镜头为固定俯角（`pitch: 52°`, `fov: 48°`, `distance: 66`），相机位于玩家上方俯瞰，画面最上沿仍向下俯视约 `28°`，**看不到远处天空穹顶与地平线**。禁止为屏幕外不可见的远景地平线、天际云海或长距离视锥浪费采样预算；所有算力集中在当前视口内可见的局部云墙、云顶、云影与阳光草地。
2. **晴天多云、云组分隔区域（禁止全图铺底云海与近景阴天雾）**：云野的核心空间感是**一组一组扎实饱满、拔地而起的巨型白积云墙将不同陆地/河口区域分隔开**，区域之间必须保持 **100% 晴朗通透**，让阳光直接照亮草地、沙滩与碧水。禁止在晴朗空域铺设全图低空云海，禁止在近中景叠加压低通透度的乳白低谷雾（否则会把晴天多云毁成整体阴天）。
3. **俯视角立体感靠“云顶菜花雕塑 + 褶皱自阴影 + 清晰冷蓝云影”**：52° 俯视下视线主要落在云顶与云墙上斜坡。云体核心必须扎实饱满、边缘柔而利落（避免糊成薄雾），通过云顶多层球泡起伏、明快奶油暖白受光顶与清澈浅天蓝/淡薰衣草蓝背光褶皱形成强烈 3D 体积感，并配合地面上清透的浅青蓝软影锚定高度空间。
4. **整体移动跟风场，原地翻涌允许持续缓慢形变与轻微局部偏移**：
   - **整体宏观位移**：云组与云墙的整体水平推进严格由模拟风场 `WindField` 积分驱动，风向改变时保留已累积位移；零风速或未接入风场时，整组云的宏观位置保持不动，绝不允许云团脱离风场自行随机乱跑。
   - **原地三维翻涌与局部微移**：在零风速和有风状态下，云体均通过确定性场景时钟驱动持续、缓慢的三维对流形变——云瓣从内部向上鼓起、舒展、边缘翻卷与融合，并允许有界的、零均值的轻微局部偏移（如表层云瓣缓慢游动与呼吸），使云朵自然鲜活而不漂离所属风场坐标。暂停时宏观风漂移与原地翻涌同时冻结。
   - **载具穿云**按玩家、敌机和地面或水面载具各自的接触高度采样。翼尖擦到云肩时，云肩只在接触侧退开。车船经过高云下方时，云层保持原来的翻涌。
5. **移动端性能预算**。默认路线 B 每个可见云簇提交一张融合索引网格，云层使用世界缓冲的原生分辨率。空域不执行云表面着色。360×640 标准档整帧绘制预算低于 150 次，三角形预算低于 150,000。路线 A 的球体追踪和分级泛光保留在开发验收入口。

## 飞机 3D low-poly 特效制作与验收

本节给出机型制作和后续运行时实现的目标。以固定战斗镜头辨认效果的起点、方向和先后为准。光球保留切面球芯与薄光晕，烟团用有明暗面的不规则多面体，气流用渐细的短带或薄弧，洞口用贴合曲面的炭黑小多边形。

### 生成飞机时标注

每个挂点记录稳定 ID、所属部件、部件局部位置与朝向、效果类型和相对强度。按机型实装构型在三视图上标注，在装配后的模型上复核。活动件的挂点随活动件运动，左右两侧、多层翼及每个发动机分别对应实际安装位置。

| 部位 | 交付的标注 | 战斗镜头要能看见的细节 |
| --- | --- | --- |
| 动力装置 | 每组排气口或喷口、出口轴向和口径。每副桨盘的中心、半径和旋向 | 侧排气先离开管口再折向机尾。双发飞机两边的喷流可独立变化 |
| 机翼与机身 | 各主翼尖、实际存在的尾翼尖、翼面气流的起边和后缘、尾流起点、机鼻冲击波中心 | 翼面气流贴面掠过后缘。翼尖细涡沿飞机已经飞过的路径弯曲 |
| 其他突出顶点 | 逐部件标出暴露于来流的轮廓尖点，例如短舱突角、支柱端、控制面凸角、外挂架或外露设备端点。保留部件与端点 ID，网格重新细分后仍可找到同一位置 | 每处端点都能拉出可辨认的短细流。以同侧主翼尖为参照，端点气流更短、更细，加速和急转时增强后仍分得出主次 |
| 武器与挂架 | 每根枪管的枪口、外抛壳武器的抛壳口及侧向、导轨或炸弹释放点 | 炮塔转动、飞机滚转或改装换枪后，发射起点仍与可见模型一致 |
| 可损部件 | 标出允许出现洞口的外表面和朝外法线。为缺少精确接触点的损伤登记可区分的表面候选位置 | 完好的皮肤连续。受损后才显出黑洞，同一翼段或发动机壳体能同时容纳多处独立破损 |

### 飞行、开火与命中

| 场景 | 形态与驱动 |
| --- | --- |
| 活塞机巡航、给油、加力 | 油门提高时，管口的排气脉冲变密、喷出距离略增。生效加力时出现短促暖亮火舌，桨尖断弧和桨盘后方的螺旋滑流加强。退出加力后旧烟随风散开 |
| 喷气机巡航、加力、收油 | 短棱锥喷流随油门伸缩。按机型配置加力时的喷口亮芯、伸长喷流或分段焰锥。焰芯之后接较淡、渐宽的尾烟，转弯后旧尾烟保留弯前航迹 |
| 直线加速、急转、穿云 | 加速时机后尾流拉长，突出点短流变清楚。急转载荷主要加强翼面薄片、主翼尖及尾翼尖涡。机鼻达到机型速度门限时掠过一层薄弧形冲击波。穿云时尾迹与现有云体空腔共用风向和航迹 |
| 机枪、机炮射击 | 每发成功射出的枪弹在对应枪口亮起一个立体低面光球，并吐出一股独立枪烟。外抛弹壳从抛壳口继承机速、侧飞、翻滚并下坠。弹头前缘的薄冲击波随弹飞行，弹体后方保留曳光 |
| 命中、火箭、导弹和炸弹 | 接触位置亮起命中光球，伴随定向碎屑与世界空间残烟。按表面选择金属火花、木布碎屑、土尘或水花。火箭和导弹从导轨离开后接推进尾烟，炸弹脱架后在实际落点显示爆点 |

### 一处破洞对应一股烟火

只有机型配置中可独立承伤的大件参与破洞选点，例如机身蒙皮、翼段、尾翼、发动机壳体和大型短舱。模型制作时显式标出大件可开洞的表面。附着于同一大件的张线、操纵索、细撑杆、索耳和小连接件都排除在命中投影与随机采样之外。它们可以随宿主运动，也可以带有气流挂点。弹道只穿过外露张线时不会开洞，继续击中后方机翼时才在翼面留下洞口。

优先使用这次命中的接触点。按命中时的机体姿态，将轮廓接触点投到对应部件的可损外表面。能定位到表面时，直接在该处开洞。只有无法定位时才随机取点：已知部件就从该部件的可损表面随机取一点，连部件也未知时就从本次实际承伤且仍附着的部件表面随机取一点。爆心、机体中心等代用坐标不能当作表面命中点。

选点只在创建洞口时执行一次，保存所属部件、局部位置和法线。黑色洞痕、烟根和火根共用该点。新位置可再开一洞，原位置再次受创可加重原洞。同一部件的两股烟在下游可以汇合，但近端要看得出分别出自哪两个黑洞。

| 损伤状态 | 洞口、烟火与余迹 |
| --- | --- |
| 受损 | 小黑洞清晰可见。按部位从洞口喷出断续细烟或短促火花 |
| 重伤 | 发动机和可燃位置从洞内亮起火根，向后依次接橙红火舌、浓烟、渐淡的旧烟。结构破洞可喷灰烟并掉落碎屑。同部件不同洞口按各自受损程度分档 |
| 禁用或维修 | 禁用发动机停止正常推进，壳体破洞保留相应火烟。维修时逐洞降低或停止发射，按恢复程度收起洞痕，已经离体的烟继续消散 |
| 脱落或整机损毁 | 洞口随所属残片离体，母机保留其余破洞。击毁爆点和碎屑先出现，火势随后衰退，坠落残件各自拖出淡淡余烟直至消散 |

### 战斗视角验收

- 在 360×640 战斗镜头下观察同一架飞机巡航、加速、急转。能分别指出主翼尖涡和突出点次级气流的起点，侧倾时起点仍贴住对应部件。
- 让同一翼段的两个分离位置受损。滚转时应看见两块黑洞和两处烟根。再让其中一处可燃破洞喷火，确认火后接浓烟。翼尖脱落时检查断口、残片和空中旧烟各自的归属。
- 大倾角双枪齐射时，逐管核对光球、逐发烟和抛壳方向。双发飞机单侧发动机受损时，核对故障侧洞口烟火和健康侧喷流。暂停、维修、重开后检查发射器及世界残留的生命周期。
- 满载时沿用有界批次，先缩短旧尾迹、减少烟团切面和光晕层数，保留不同起点的可辨性与逐发枪烟的节奏。按下文标准档整帧预算验收。

## 飞机涂装与云野光感

飞机涂装通过稳定的 livery ID 和纯数据描述接入 3D 内容库。每个描述提供主色、次色、饰边色、色带模式和面板明暗范围。机型仍可使用历史 `color` 与 `accent`，缺少显式涂装时由确定性的 `legacy:<frameId>` 映射补齐。涂装不保存 Three.js 材质、纹理或运行时状态。

飞机材质沿用程序化几何和共享材质租约，在局部坐标中生成有限频率的色带、翼面分区和低频面板变化。主色、次色与饰边必须在 360×640 固定俯视战斗镜头下保持可辨识，损伤、发热和部件高亮在涂装之后叠加。省电档关闭面板噪声并降低边缘光采样，保留主次色、饰边、轮廓和云影明暗差异。

福克 Dr.I 的参考图册现以 `DR1_LIVERY_IDS` 登记 12 套无贴图涂装。棋盘使用局部坐标网格，朱砂金叉与深海铜绿使用十字臂，珊瑚十字带与午夜鎏金使用色带，金尾海锚、蜜杏青锚和炭黑尾翼使用尾段分区。翼色和尾色作为涂装数据的可选模块基色下发到同一工厂，因此机库切换涂装不会复制几何或材质。展厅的左右涂装按钮只改变预览机体的内容 ID，出击默认使用 01「橄榄棋盘」。

飞机与云层共享当前太阳方向、时代色板和云影采样。朝向太阳的面使用明快暖色，背光面保留浅蓝或淡紫冷影，天空反弹和边缘光保持低强度。云影覆盖时只降低受光并增加冷色过渡，云内包裹只作用于局部颜色和轮廓光，飞机轮廓与机头方向持续可读。机库预览、玩家机、敌机和 NPC 批处理使用同一涂装与受光语义。

固定验收至少覆盖三翼机、单翼机和喷气机，分别观察机库、战斗、滚转、云影推进和云内状态。标准档将飞机材质、绘制和三角形计入 360×640 满战斗预算。开发诊断记录涂装 ID、共享材质数量、活动实例数量、环境受光状态和质量级别。

## 双 Pass 渲染与玩家可见性

主渲染器使用同一相机执行两遍渲染，保证云层参与世界遮挡同时玩家与关键战斗信息始终可读：

```text
主场景（写入颜色与深度）
  地形块、水面、植被、地面单位、敌机、敌方弹道、爆炸、世界特效
云阶段与深度感知合成
  对视线与连续云层交段积分并在最近世界表面截断，抑制云色跨过物体轮廓
清除深度（clearDepth）
覆盖层
  玩家飞机、玩家弹道、锁定环、准心、投弹轨迹
DOM 层
  雷达、边缘威胁指示、HUD、击毁反馈（被云遮挡敌机名牌随可见性淡出）
```

## 确定性地形与地表色板

### 高度场与地形块

地形高度只由 `seed + worldX + worldZ` 决定，禁止依赖玩家状态、画质档位或随机调用，模拟层与渲染层共同读取 `surfaceHeight()`、`terrainNormal()`、`isWater()` 与路线遮罩。

```text
域扭曲 → 低频主体起伏 → 高频细节 → 山脊抬升 → 河道下切与水面限制 → 道路/铁路/桥面压平
```

`src/rendering/TerrainChunks.ts` 以 `TERRAIN.chunkRadius = 2` 维护玩家周围 5×5 共 25 块真实高度网格。每块为 80×80 世界单位，统一使用 `TERRAIN.segments = 40` 的 40×40 网格，并在玩家跨越块边界时复用或重建活动块。顶点写入 `position`、`normal` 和 `roadMask`，地形与模拟层通过同一套 `sampleTerrain()` 查询高度、水面和岸线；水面网格复用地形三角形并按最终河床裁切。shader 负责大色块三段式明暗、轻微颗粒与光照，不再偏移高度。

## 连续体积云层与风动植被

### 连续密度云场

翡翠海岸由东侧云墙和西侧低云脊围出河道，北侧云带横切飞行路径。路线 B 从确定性的平滑融合距离场生成索引网格，预计算表面法线、褶皱遮蔽与侧光。渲染器最多选择四簇，按视锥裁剪，并保留最近使用的八张云簇网格。

- **风场积分位移**：云流场读取当前飞行位置的 `WindField.sample(x, z)`，每帧将风速向量乘以场景时间增量累加到世界位移，阵风按比例放大；风向改变时保留历史位移。云壁、远景云带、云影和 CPU 遮挡查询共享同一位移向量。
- **自发形变**：云体独立推进自发形变相位，由固定在云体坐标中的低频三维噪声驱动局部鼓起、收缩和边缘呼吸；风速与阵风平滑提高形变频率与幅度，暂停时位移和形变同时冻结。
- **云壁着色**由插值法线、奶油暖白亮顶、暖珠光中间调和冷蓝紫褶皱组成。标准与高档增加由 `32³` 噪声驱动的微法线。
- **当前切口**跟随机身、翼尖或车船的前、中、后部。主体切口最大半径为 2.1 个世界单位，其余接触点为 1.4，薄云处按密度缩小。A 和 B 共用距离场平滑减法，融合宽度为 0.18 个世界单位。B 用网格绘制整片云，只在接触处将云组距离场的零值和斜率对齐到已翻涌、受尾流挤压的云面，沿视线求减法后的表面，用该处梯度计算受光并写入深度。
- **经过后的尾流**沿载具各自的实际轨迹压低云面，在半径 8 个世界单位内带起云肩。最多 48 段轨迹由各载具共享。载具离场后遗留的轨迹随风漂移，在 2.4 秒内逐段回拢。相机进入云内时雾化随密度增强，玩家覆盖层最后绘制。地表和水面的软影与云墙同步漂移。

### 风动草地、树木与水面

- **草地与草簇**：草地通过世界坐标色带表现风吹波浪；标准与高档补充实例化草簇，共用模拟地表高度、道路遮罩（`< 0.30`）与坡度过滤（`≤ 0.40`）。
- **风动树木**：树根贴合最终地表高度（道路遮罩 `< 0.30`、坡度 `≤ 0.48`），采样与 `WindField` 一致的空间风向，弯曲权重随顶点相对高度平方增长，刚度由种子确定（`0.55–1.00`）。
- **水面与统一时钟**：水面波纹共享同一组风场 uniforms；云层、草浪、树木与水面共用渲染场景时钟，暂停时全部停在当前相位。
