# 程序化 3D 和 shader 表现

> 本文记录 0.3.0 阶段的初版设计。当前实现见下列入口。[程序化飞机规格](../../openspec/specs/rendering/procedural-aircraft/spec.md) · [运行时内容库规格](../../openspec/specs/rendering/runtime-content-library/spec.md)

## 视觉方向

游戏使用风格化 lowpoly 形体，强调真实的空间关系、材质反应、命中反馈和光照变化。几何体保持简单，材质和动态效果负责传达重量、速度、受损和天气。

程序化资源的目标是让升级可以实时改变飞机形状，让部件损坏可以实时变黑、冒烟、喷火和脱落，同时避免依赖外部贴图。

## 几何体生成

### 机身

机身由一组截面沿 Z 轴采样生成。每个截面保存半宽、半高、圆角和材质区域。

```ts
type FuselageSection = {
  z: number
  halfWidth: number
  halfHeight: number
  cornerRadius: number
  materialId: string
}
```

前后升级通过增加截面或改变截面间距完成。机头雷达罩、驾驶舱和尾部喷口使用单独几何体，方便独立命中和损坏。

### 机翼

机翼由根部、翼尖、前掠角、后掠角、厚度和折角参数生成。

```ts
type WingRecipe = {
  side: 'left' | 'right'
  rootPosition: Vector3
  span: number
  chord: number
  sweep: number
  dihedral: number
  thickness: number
  tipShape: 'square' | 'cut' | 'rounded'
}
```

新增发动机或外挂武器时，机翼先扩大到新的挂点，再把部件安装到扩展后的几何体上。

### 发动机和炮塔

- 发动机使用低分段圆柱、喷口环和连接支架
- 炮塔使用底座、旋转环、炮塔壳体和炮管
- 机翼武器使用挂架、弹药箱和枪管
- 损坏后的断裂件使用预先定义的低面数碎片几何体

## 材质

每个物体共享一组材质参数。

```ts
type LowPolyMaterialParams = {
  baseColor: Color
  roughness: number
  metalness: number
  edgeColor: Color
  edgeStrength: number
  noiseScale: number
  damageAmount: number
  heatAmount: number
  partSeed: number
}
```

材质不使用贴图。颜色、粗糙度和边缘光通过世界坐标、法线、部件种子和时间噪波计算。

## Shader 规划

### aircraft shader

- 使用平面或低频法线增强 lowpoly 面的层次
- 按部件种子加入轻微颜色偏差
- `damageAmount` 增加黑斑、裂纹和局部粗糙度
- `heatAmount` 让发动机和受击部件出现红色或橙色热量
- `edgeStrength` 保留云层和阴影中的轮廓

### smoke shader

- 通过噪波和软粒子形成黑烟体
- 烟雾沿局部速度和风场方向偏移
- 发动机损坏越重，烟雾密度和尺寸越大
- 烟雾不遮挡锁定环和关键 UI

### fire shader

- 火焰使用多层 billboard 或低面数锥体
- 外层为橙色，中心为白黄色
- 受风影响产生侧向偏移
- 发动机 `critical` 时火焰间歇性喷出，`disabled` 时变短并降低亮度

### terrain shader

- 通过高度、法线和噪波混合土地、沙地、道路和焦黑区域
- 爆炸后在局部坐标上增加短时焦痕和尘土
- 远处降低材质频率，避免移动端过度采样
- 草地顶点提供遮罩，片元用世界坐标、风向、阵风与场景时间生成低对比度移动色带。道路、水面、岸边和陡坡保留各自的地表显示。
- 标准和高档在草地上补充实例化三叶草簇。草簇每块上限分别为 12 和 24，省电档使用地表色带。

### cloud shader

- 云墙、云脊和地面开口统一由世界坐标的覆盖及高度纹理定义。预计算的太阳遮蔽与三维噪声塑造暖白受光面、蓝色凹处和松散的边缘。
- 三档共享云层布局。省电、标准和高档的云缓冲为主缓冲每轴 40%、50%、65%，视线采样上限分别为 12、18、24 步。
- 云流场读取 `WindField.sample(x, z)`。风向旋转云瓣的卷动轴，风速控制推进速度，阵风加强推进与细节噪声。风向和速度使用平滑追踪，云瓣保留高度相位来维持体积起伏，水平漂移不叠加独立随机横移。云的颜色、地面阴影和遮挡测试共享这套流动状态。
- 云体有独立的低频自发形变时间。覆盖噪声负责云瓣鼓起、收缩和融合，侵蚀噪声负责边缘呼吸。无风时形变保持低速，风速和阵风提高形变频率与幅度。形变使用固定种子和连续空间噪声。
- 近景云壁由连续低密度底形连接主云瓣。风偏移与自发形变分离，固定世界坐标保持噪声连续，垂直高度相位保留云体的上下起伏。
- 自发形变使用固定坐标样本之间的低频连续混合和小幅局部形变偏移，不滚动整片噪声，也不叠加独立横向漂移。云墙对邻近体素采样做平滑融合，避免垂直切片形成条带。
- 玩家位置和水平速度驱动局部空腔与尾流。空腔按玩家高度衰减，尾流沿玩家速度方向延伸，并与云的风漂移使用同一世界坐标变换。
- 水面波纹使用同一组风场 uniforms。风向、风速、阵风和场景时间共同控制水面噪声与细波相位。
- 世界深度截断云的密度积分，并参与低分辨率云缓冲的上采样。云内可见度随视线上的透射率连续改变。清除深度后绘制玩家机、玩家弹道和瞄准信息。

### tree shader

- 树根使用最终地表高度，弯曲权重随顶点相对高度平方增加。相位、刚度、比例和颜色由种子及世界坐标生成。
- 树木在根部采样与 `WindField` 相同的空间风向，刚度范围为 0.55–1.00。省电档以 0.65 的频率系数使用简化摆动，标准档使用 1.00，高档在 1.00 基础上增加 0.14 的树冠抖动。
- 云、草地和树木共用暂停时停止的场景时钟。完整预算和浏览器验收入口见[连续云层与风动植被](../IMPLEMENTATION_0_4_TERRAIN_CLOUD.md#连续云层与风动植被)。

### crosshair shader

- 外圈半径由稳定度驱动
- 锁定时扇形宽度由锁定进度驱动
- 颜色在蓝、黄、红、绿之间平滑过渡
- 地面投影使用深色半透明圆盘和动态噪波边缘

## 受损部件表现管线

1. 碰撞系统确定命中部件。
2. 部件数据更新生命、损坏状态和热量。
3. 渲染层读取 `damageAmount`、`smokeLevel` 和 `fireLevel`。
4. 部件材质更新黑斑、裂纹、热量和边缘光。
5. 特效系统在部件挂点生成火花、烟和火焰。
6. 如果状态为 `destroyed`，播放脱落动画并从可用碰撞体中移除。

## 性能策略

- 几何体模板共享 BufferGeometry，实例只保存变换和材质参数
- 弹道、烟雾、火焰、金币和碎片使用对象池
- 远处敌人降低几何体面数和粒子数量
- 低端设备关闭部分透明层并降低动态分辨率
- 使用单一主方向光加简化环境光，避免移动端大量动态光源
- 只对近距离和关键部件显示实时损坏细节

## 透视相机和 lowpoly 的关系

透视相机会让靠近相机的机翼和弹道放大，因此大型机体的迎弹面会有更强的空间感。相机保持固定俯视角，避免自由旋转造成控制方向和视觉方向脱节。

## 验收标准

- 飞机、敌人和地面目标都可以由简单几何体运行时生成。
- 升级增加部件后，模型、碰撞体和材质挂点同步扩展。
- 发动机受损后烟雾和火焰随状态变化，且受风影响。
- lowpoly 平面、边缘光、粗糙度和噪波能传达材质差异。
- 移动端质量档位能降低透明层、粒子和分辨率压力。
